# 6학년 2학기 과학 2단원 「물질의 연소」— (7차시) 연소 생성물은 생태계에 어떤 피해를 줄까?

> **안내**: 이 자료는 업로드해 주신 **2단원 지도서(48~49쪽, 「실험관찰」30~31쪽)**를 근거로 작성했습니다. 이 차시는 **과학-기술-사회(STS) 학습 모형**을 적용하며, 6차시에서 확인한 "양초가 연소하면 물과 이산화 탄소가 생성된다"는 개념을 이어받아, 그중 **이산화 탄소가 실제로 생태계에 어떤 피해를 주는지** 조사·분석하는 차시입니다.

---

## 1. 📖 핵심 개념 상세 정리

### 학습 목표
- 연소 생성물로 인한 생태계 피해 사례를 조사하여 설명할 수 있다. *(지식·이해, 과정·기능)*
- 연소 생성물로 인한 생태계 피해 사례를 수집하여 분석할 수 있다. *(과정·기능)*
- 성취기준 **[6과14-04]** 연소 과정에서 생성되는 물질로 인한 생태계의 피해 사례를 수집하고 분석하여 해결책을 제안하고 공유할 수 있다.

### 핵심 개념 (6학년 눈높이 설명)
- 자동차·비행기 같은 교통수단, 가스레인지, 화력 발전소, 쓰레기 소각장 등 우리 생활 곳곳에서 연소가 끊임없이 일어나고 있습니다.
- 연소가 일어날수록 연소 생성물인 **이산화 탄소**가 대기 중에 계속 쌓입니다.
- 대기 중 이산화 탄소가 많아지면 **기후변화**가 일어나고, 그 영향으로 다음과 같은 생태계 피해가 실제로 나타나고 있습니다.
  - **구상나무 집단 고사**: 한라산·지리산·덕유산 등에만 분포하는 우리나라 고유종 침엽수인 구상나무가, 기온 상승과 수분 부족으로 집단 고사 위기에 처해 있습니다.
  - **산호초 백화현상**: 대기 중 이산화 탄소의 일부가 바다에 녹아 **해양 산성화**가 일어나고, 동시에 수온이 오르면서 산호초가 하얗게 변하고 약해집니다.
  - **조개류 껍데기 손상**: 해양이 산성화되면 조개·굴 같은 생물의 석회질 껍데기가 얇아지거나 쉽게 깨집니다.
  - **북극곰 멸종 위기**: 지구 온난화로 북극 해빙이 줄어들면서, 해빙에 의존해 사냥하는 북극곰이 먹이 찾기에 어려움을 겪고 있습니다(국제자연보전연맹(IUCN) 멸종 취약종 지정).
- 즉, **연소 생성물인 이산화 탄소 하나가 늘어나는 것만으로도, 숲·바다·극지방처럼 서로 멀리 떨어진 다양한 생태계에 동시에 영향을 줍니다.**

### 🗣️ 설명 스크립트 예시 (도입부 활용)
> "자동차는 어떻게 움직일까요? 기름이나 가스를 연료로 태워서(연소해서) 움직여요. 그런데 자동차가 많이 다닐수록, 또 우리가 전기를 많이 쓸수록 연소도 더 많이 일어나고, 그때마다 이산화 탄소도 더 많이 나와요. 이 이산화 탄소가 쌓이면 지구 반대편 북극의 얼음도, 우리나라 한라산의 나무도, 저 멀리 바닷속 산호초도 영향을 받는다는 사실, 알고 있었나요? 오늘은 연소 생성물이 생태계에 실제로 어떤 피해를 주고 있는지 조사해 볼 거예요."

## 2. 🔎 조사 활동 완벽 가이드 — 연소 생성물로 인한 생태계 피해 사례 조사하기

이 차시는 실험보다 **조사·분석·토의** 중심으로 진행됩니다(과학-기술-사회 STS 학습 모형).

### 활동 목표
- 연소 생성물(이산화 탄소)로 인한 생태계 피해 사례를 수집하고 분석할 수 있다.

### 준비물
| 준비물 | 비고 |
|---|---|
| 스마트 기기(태블릿·컴퓨터) | 인터넷 조사용 |
| 참고 도서 | 환경 관련 도서 |
| 학급/모둠 공유 플랫폼 | 조사 결과 공유·저장용 |

### 활동 단계
1. **문제 인식**: "자동차가 움직이는 것과 연소는 어떤 관계가 있을까?"를 이야기하며, 자동차 운행이 많아질수록 연소 생성물(이산화 탄소)도 많이 발생한다는 것을 확인합니다.
2. **자료 수집**: "이산화 탄소 바다 생태계", "이산화 탄소 숲 생태계", "이산화 탄소 극지 생태계" 등 구체적인 검색어로 모둠별 피해 사례를 조사합니다. (범위가 너무 방대해지지 않도록 검색어를 좁혀서 안내하는 것이 중요합니다.)
3. **비교 분석**: 조사한 사례에서 **원인**과 **현황**을 표로 정리합니다.

   | 사례 | 원인 | 현황 |
   |---|---|---|
   | 구상나무 고사 | 대기 중 이산화 탄소 증가로 인한 기후변화 | 한라산 등 고유 군락이 집단 고사 위기 |
   | 산호초 백화 | 해양 산성화 + 수온 상승 | 산호초가 하얗게 변하며 약해짐 |
   | 조개류 손상 | 해양 산성화 | 껍데기가 얇아지거나 쉽게 깨짐 |
   | 동식물 감소 | 기후변화에 적응하지 못함 | 개체 수 감소·멸종 위기 |

4. **결론 도출**: 조사한 사례들의 공통점을 이야기합니다 → "이산화 탄소로 인한 다양한 생태계 피해 사례는 이산화 탄소의 배출량이 증가하기 때문에 발생한다."
5. **해결책 제안**: 이산화 탄소로 인한 생태계 피해를 줄이기 위한 방법을 이야기합니다 → "대기 중으로 배출되는 이산화 탄소의 양을 줄여야 한다." (이 제안은 다음 8~9차시 "실천 방법 홍보 자료 만들기"로 자연스럽게 이어집니다.)
6. 조사한 내용을 공유 플랫폼에 올려 다른 모둠과 공유하고, 서로의 조사 결과에 댓글로 피드백합니다.

### ⚠️ 유의사항
- 조사 학습을 하기 전에 **인터넷 사용 윤리**를 반드시 안내합니다.
- 조사한 내용을 공유 플랫폼에 올릴 때는 **출처를 기재**하거나 원문과 링크로 연결하도록 지도합니다.
- 스마트 기기에서 냄새가 나거나 열이 발생하면 즉시 사용을 중지하고 교사에게 알리도록 안내합니다.
- 검색 내용이 너무 방대하면 찾기 어려우므로, 검색어를 구체적으로 좁혀서 안내합니다.

## 3. 🛡️ 오개념 철벽 방어

### 오개념 1 — "이산화 탄소는 우리가 숨 쉴 때도 나오는 기체인데 뭐가 문제일까?"
- **왜 문제인가**: 사람의 호흡으로 나오는 이산화 탄소의 양은 자연적인 탄소 순환 안에서 균형을 이루지만, **화석 연료의 연소로 대량 배출되는 이산화 탄소는 이 균형을 깨뜨릴 만큼 많은 양**입니다. "이산화 탄소 자체가 나쁜 기체"라는 것이 아니라 "양이 너무 많아지는 것"이 문제라는 점을 짚어 주어야 합니다.
- **교정 발문**: "우리가 숨 쉬는 것과 자동차 수백만 대가 매일 연료를 태우는 것, 이산화 탄소가 늘어나는 속도가 같을까요?"

### 오개념 2 — "생태계 피해는 먼 나라, 먼 미래의 이야기다"
- **왜 문제인가**: 구상나무는 **우리나라 고유종**이며, 한라산의 구상나무 숲은 2009년과 2016년 사진만 비교해도 눈에 띄게 줄어들 만큼 이미 진행 중인 문제입니다. "먼 훗날 다른 나라 이야기"가 아니라 "지금 우리나라에서 일어나는 일"임을 실제 사진 자료로 확인시켜야 합니다.
- **교정 발문**: "북극곰 이야기는 많이 들어봤는데, 우리나라에도 이산화 탄소 때문에 피해를 겪는 생물이 있을까요?"

### 오개념 3 — "산호초가 하얗게 변하는 건 원래 색깔이 그런 것뿐이다(백화=탈색을 단순한 색 변화로 오해)"
- **왜 틀렸나**: 산호초의 흰색은 단순한 색 변화가 아니라, 산호와 공생하던 조류(색을 내는 미생물)가 스트레스로 빠져나가면서 **산호가 죽어가는 신호**입니다. 백화된 산호초는 결국 죽어 그 안에 살던 수많은 물고기·생물의 서식지가 사라집니다.
- **교정 발문**: "산호초가 하얗게 변하고 난 뒤, 그곳에 살던 물고기들은 어떻게 될까요?" (시뮬레이터에서 백화가 진행될수록 물고기가 사라지는 모습으로 확인 가능)

## 4. 💡 호기심 천국 & 심화 탐구 (영재 교육 연계)

- **과학자 이야기 — 조지프 블랙(Joseph Black, 1728~1799)**: 영국의 화학자·물리학자로, 1754년 탄산 마그네슘을 가열하는 실험 중 **이산화 탄소를 세계 최초로 발견**했습니다. 그는 이산화 탄소가 공기 중에도 존재한다는 사실을 예측하기도 했습니다. 오늘날 우리가 걱정하는 "대기 중 이산화 탄소 증가" 문제의 출발점이 된 발견이라 할 수 있습니다.
- **해양 산성화의 화학**: 이산화 탄소가 바닷물에 녹으면 탄산이 되어 바닷물의 산성도를 높입니다. 이 때문에 조개·산호처럼 탄산 칼슘 껍데기·골격을 가진 생물들이 껍데기를 만들거나 유지하기 어려워집니다.
- **다른 온실가스와의 비교**: 이산화 탄소 외에도 메탄(가축의 소화 과정, 매립지 등에서 발생)처럼 온실효과를 일으키는 기체가 여러 가지 있습니다. "왜 유독 이산화 탄소를 가장 많이 이야기할까?"(배출량이 압도적으로 많고, 대기 중에 수백 년간 머물기 때문)를 함께 탐구해 볼 수 있습니다.
- **생각해 볼 질문(영재 학급용)**: "만약 전 세계가 오늘부터 화석 연료 연소를 완전히 멈춘다면, 이미 대기 중에 쌓인 이산화 탄소로 인한 생태계 피해는 바로 멈출까요, 아니면 한동안 계속될까요? 그 이유는 무엇일까요?"

```html
(function(){
  const canvas = document.getElementById('stage');
  const ctx = canvas.getContext('2d');
  let W = 900, H = 1125;

  function resizeCanvas(){
    const rect = canvas.getBoundingClientRect();
    const dpr = window.devicePixelRatio || 1;
    W = rect.width; H = rect.height;
    canvas.width = Math.max(1, Math.round(W*dpr));
    canvas.height = Math.max(1, Math.round(H*dpr));
    ctx.setTransform(dpr,0,0,dpr,0,0);
  }

  const PPM_MIN = 280, PPM_MAX = 600, PPM_NOW = 420;

  let GRID_TOP, GRID_BOTTOM, CARD_GAP, cardW, cardH, col0X, col1X, row0Y, row1Y;
  let titleFont, cardTitleFont, capFont;

  function computeLayout(){
    GRID_TOP = H*0.10;
    GRID_BOTTOM = H*0.86;
    CARD_GAP = W*0.03;
    cardW = (W - W*0.06 - CARD_GAP) / 2;
    cardH = (GRID_BOTTOM - GRID_TOP - CARD_GAP) / 2;
    col0X = W*0.03; col1X = col0X + cardW + CARD_GAP;
    row0Y = GRID_TOP; row1Y = row0Y + cardH + CARD_GAP;
    titleFont = W*0.042;
    cardTitleFont = W*0.036;
    capFont = W*0.032;
  }

  const ppmSlider = document.getElementById('ppmSlider');
  const ppmVal = document.getElementById('ppmVal');
  const showNow = document.getElementById('showNow');
  const riseOut = document.getElementById('riseOut');
  const stageOut = document.getElementById('stageOut');
  const riseBar = document.getElementById('riseBar');
  const stageBar = document.getElementById('stageBar');

  function clamp(v,a,b){ return Math.max(a, Math.min(b, v)); }
  function lerp(a,b,t){ return a + (b-a)*t; }
  function lerpColor(c1,c2,t){
    return [Math.round(lerp(c1[0],c2[0],t)), Math.round(lerp(c1[1],c2[1],t)), Math.round(lerp(c1[2],c2[2],t))];
  }
  function rgb(c){ return `rgb(${c[0]},${c[1]},${c[2]})`; }

  function severity(ppm){ return clamp((ppm-PPM_MIN)/(PPM_MAX-PPM_MIN), 0, 1); }
  function stageInfo(t){
    if(t < 0.25) return { name:'안전', color:'#3f7d54' };
    if(t < 0.5) return { name:'주의', color:'#c9a227' };
    if(t < 0.75) return { name:'위험', color:'#d9772e' };
    return { name:'심각', color:'#d9432b' };
  }

  function updateSliderFill(){ /* 슬라이더 배경은 CSS 그라데이션 고정 사용 */ }

  // ---- 카드 공통 틀 ----
  function drawCardFrame(x, y, w, h, title, skyTop, skyBottom){
    ctx.save();
    ctx.beginPath();
    const r = w*0.03;
    ctx.moveTo(x+r,y);
    ctx.arcTo(x+w,y,x+w,y+h,r);
    ctx.arcTo(x+w,y+h,x,y+h,r);
    ctx.arcTo(x,y+h,x,y,r);
    ctx.arcTo(x,y,x+w,y,r);
    ctx.closePath();
    ctx.clip();

    const grad = ctx.createLinearGradient(0,y,0,y+h);
    grad.addColorStop(0, skyTop);
    grad.addColorStop(1, skyBottom);
    ctx.fillStyle = grad;
    ctx.fillRect(x,y,w,h);

    return { clipRestore: ()=>ctx.restore() };
  }

  function drawCardTitle(x, y, w, title){
    ctx.fillStyle = 'rgba(255,255,255,0.92)';
    ctx.fillRect(x, y, w, cardTitleFont*1.9);
    ctx.fillStyle = '#3a3226';
    ctx.font = 'bold ' + cardTitleFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'left';
    ctx.fillText(title, x + w*0.04, y + cardTitleFont*1.3);
  }

  // 1) 구상나무 숲
  function drawForestCard(x,y,w,h,t){
    const frame = drawCardFrame(x,y,w,h, '구상나무 숲', '#cdeaff', '#eaf3e0');
    const groundY = y + h*0.78;
    ctx.fillStyle = '#cdb98a';
    ctx.fillRect(x, groundY, w, h - (groundY-y));

    const healthy = [63,141,84], dead = [138,120,96];
    const nTrees = 5;
    for(let i=0;i<nTrees;i++){
      const fx = x + w*(0.14 + i*0.18);
      const dead_i = t > (i+1)/(nTrees+1); // 심각도가 높을수록 더 많은 나무가 고사
      const treeH = h*0.30;
      const baseY = groundY;
      if(dead_i){
        ctx.strokeStyle = rgb(dead);
        ctx.lineWidth = Math.max(2, w*0.012);
        ctx.beginPath();
        ctx.moveTo(fx, baseY);
        ctx.lineTo(fx - w*0.01, baseY - treeH*0.9);
        ctx.stroke();
        ctx.beginPath();
        ctx.moveTo(fx, baseY - treeH*0.35);
        ctx.lineTo(fx + w*0.035, baseY - treeH*0.55);
        ctx.stroke();
      } else {
        const localT = clamp(t*(nTrees+1) - i, 0, 1)*0.6;
        const col = rgb(lerpColor(healthy, dead, localT));
        ctx.fillStyle = col;
        for(let s=0;s<3;s++){
          const segH = treeH*0.4;
          const segY = baseY - s*segH*0.62;
          const segW = w*0.09*(1 - s*0.18);
          ctx.beginPath();
          ctx.moveTo(fx, segY-segH);
          ctx.lineTo(fx-segW, segY);
          ctx.lineTo(fx+segW, segY);
          ctx.closePath();
          ctx.fill();
        }
        ctx.strokeStyle = '#6b4a2c';
        ctx.lineWidth = Math.max(1.5, w*0.006);
        ctx.beginPath();
        ctx.moveTo(fx, baseY);
        ctx.lineTo(fx, baseY - treeH*0.15);
        ctx.stroke();
      }
    }
    frame.clipRestore();
    drawCardTitle(x,y,w,'구상나무 숲');

    const alive = nTrees - Math.round(t*nTrees);
    ctx.fillStyle = '#3a3226';
    ctx.font = capFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText('건강한 나무 ' + Math.max(alive,0) + '/' + nTrees + '그루', x+w/2, y+h - capFont*0.6);
    ctx.textAlign = 'left';
  }

  // 2) 산호초
  function drawReefCard(x,y,w,h,t){
    const frame = drawCardFrame(x,y,w,h, '산호초', '#bfe3ff', '#1c5f8a');
    const vivid = [214,64,120], bleached = [255,255,255];
    const positions = [[0.22,0.72],[0.42,0.62],[0.62,0.75],[0.8,0.6],[0.5,0.85]];
    positions.forEach(([px,py], i)=>{
      const cx = x + w*px, cy = y + h*py;
      const localT = clamp(t*1.3 - i*0.06, 0, 1);
      const col = rgb(lerpColor(vivid, bleached, localT));
      ctx.fillStyle = col;
      ctx.strokeStyle = 'rgba(0,0,0,0.12)';
      ctx.lineWidth = 1;
      const branches = 5;
      for(let b=0;b<branches;b++){
        const ang = -Math.PI/2 + (b-(branches-1)/2)*0.32;
        const len = w*0.09;
        ctx.beginPath();
        ctx.moveTo(cx,cy);
        ctx.lineTo(cx+Math.cos(ang)*len, cy+Math.sin(ang)*len);
        ctx.lineWidth = Math.max(3, w*0.02);
        ctx.strokeStyle = col;
        ctx.lineCap = 'round';
        ctx.stroke();
      }
    });
    // 물고기(피해가 심할수록 옅어짐 = 떠나감)
    ctx.globalAlpha = clamp(1 - t*1.1, 0, 1);
    ctx.fillStyle = '#ffcf5c';
    [[0.28,0.32],[0.62,0.25],[0.75,0.4]].forEach(([px,py])=>{
      const fx = x+w*px, fy=y+h*py, s=w*0.028;
      ctx.beginPath();
      ctx.moveTo(fx-s,fy); ctx.lineTo(fx+s,fy-s*0.6); ctx.lineTo(fx+s,fy+s*0.6); ctx.closePath(); ctx.fill();
    });
    ctx.globalAlpha = 1;
    frame.clipRestore();
    drawCardTitle(x,y,w,'산호초');

    ctx.fillStyle = '#eef7ff';
    ctx.font = capFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText('백화 정도 ' + Math.round(t*100) + '%', x+w/2, y+h - capFont*0.6);
    ctx.textAlign = 'left';
  }

  // 3) 조개류
  function drawShellCard(x,y,w,h,t){
    const frame = drawCardFrame(x,y,w,h, '조개류', '#bfe3ff', '#e8dcb8');
    const groundY = y+h*0.62;
    ctx.fillStyle = '#e3d3a0';
    ctx.fillRect(x, groundY, w, h-(groundY-y));

    const positions = [[0.28,0], [0.52,1], [0.76,0]];
    positions.forEach(([px], i)=>{
      const cx = x + w*px, cy = groundY - h*0.05;
      const rShell = w*0.09 * (1 - t*0.28);
      ctx.save();
      ctx.translate(cx,cy);
      ctx.fillStyle = '#e9e4d6';
      ctx.strokeStyle = '#a89a78';
      ctx.lineWidth = Math.max(1.5, w*0.006);
      ctx.beginPath();
      ctx.ellipse(0,0, rShell, rShell*0.78, 0, 0, Math.PI*2);
      ctx.fill();
      ctx.stroke();
      // 부채살 무늬
      ctx.strokeStyle = 'rgba(150,130,90,0.5)';
      for(let k=-3;k<=3;k++){
        ctx.beginPath();
        ctx.moveTo(0,0);
        ctx.lineTo(Math.sin(k*0.25)*rShell, -Math.cos(k*0.25)*rShell*0.78);
        ctx.stroke();
      }
      // 심각도가 높을수록 금(균열)이 보임
      if(t > 0.35){
        ctx.strokeStyle = 'rgba(120,40,20,0.7)';
        ctx.lineWidth = Math.max(1.5, w*0.007);
        const crackN = t > 0.7 ? 3 : 1;
        for(let c=0;c<crackN;c++){
          ctx.beginPath();
          ctx.moveTo(-rShell*0.3 + c*rShell*0.25, -rShell*0.5);
          ctx.lineTo(rShell*0.1 - c*rShell*0.2, rShell*0.5);
          ctx.stroke();
        }
      }
      ctx.restore();
    });
    frame.clipRestore();
    drawCardTitle(x,y,w,'조개류');

    ctx.fillStyle = '#3a3226';
    ctx.font = capFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'center';
    const label = t < 0.35 ? '껍데기가 튼튼해요' : (t < 0.7 ? '껍데기가 얇아져요' : '껍데기가 잘 깨져요');
    ctx.fillText(label, x+w/2, y+h - capFont*0.6);
    ctx.textAlign = 'left';
  }

  // 4) 북극 해빙
  function drawArcticCard(x,y,w,h,t){
    const frame = drawCardFrame(x,y,w,h, '북극 해빙', '#eaf6ff', '#2f6fa8');
    const cx = x + w*0.5, cy = y+h*0.62;
    const iceScale = lerp(1, 0.32, t);
    ctx.fillStyle = 'rgba(255,255,255,0.95)';
    ctx.beginPath();
    ctx.ellipse(cx, cy, w*0.36*iceScale, h*0.14*iceScale, 0, 0, Math.PI*2);
    ctx.fill();
    ctx.strokeStyle = 'rgba(150,190,220,0.8)';
    ctx.lineWidth = Math.max(1.5, w*0.006);
    ctx.stroke();

    // 북극곰
    const bx = cx, by = cy - h*0.14*iceScale*0.4;
    const bs = w*0.09;
    ctx.fillStyle = '#fdfdf6';
    ctx.strokeStyle = 'rgba(150,140,110,0.6)';
    ctx.lineWidth = 1;
    ctx.beginPath();
    ctx.ellipse(bx, by, bs, bs*0.62, 0, 0, Math.PI*2);
    ctx.fill(); ctx.stroke();
    ctx.beginPath();
    ctx.ellipse(bx+bs*0.85, by-bs*0.15, bs*0.42, bs*0.34, 0, 0, Math.PI*2);
    ctx.fill(); ctx.stroke();

    frame.clipRestore();
    drawCardTitle(x,y,w,'북극 해빙');

    ctx.fillStyle = '#eef7ff';
    ctx.font = capFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText('해빙 면적 ' + Math.round((1-t)*100) + '%', x+w/2, y+h - capFont*0.6);
    ctx.textAlign = 'left';

  function drawScene(){
    computeLayout();
    const ppm = parseFloat(ppmSlider.value);
    ppmVal.textContent = ppm.toFixed(0) + 'ppm';
    const t = severity(ppm);
    const st = stageInfo(t);

    ctx.clearRect(0,0,W,H);
    ctx.fillStyle = '#faf7ee';
    ctx.fillRect(0,0,W,H);

    ctx.fillStyle = '#3a3226';
    ctx.font = 'bold ' + titleFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'left';

    drawForestCard(col0X, row0Y, cardW, cardH, t);
    drawReefCard(col1X, row0Y, cardW, cardH, t);
    drawShellCard(col0X, row1Y, cardW, cardH, t);

    if(showNow.checked){
      ctx.fillStyle = st.color;
      ctx.font = 'bold ' + capFont.toFixed(1) + 'px sans-serif';
      ctx.textAlign = 'left';
      ctx.fillText('※ 오늘날 대기 중 농도는 약 ' + PPM_NOW + 'ppm이에요', W*0.03, H*0.925);

    riseOut.textContent = '+' + riseAmt.toFixed(0) + 'ppm';
    riseBar.style.width = clamp(riseAmt/(PPM_MAX-PPM_MIN)*100, 4, 100) + '%';
    riseBar.style.background = st.color;

    stageOut.textContent = st.name;
    stageBar.style.width = clamp(t*100, 4, 100) + '%';
    stageBar.style.background = st.color;
  }

  [ppmSlider, showNow].forEach(el=>{
    el.addEventListener('input', drawScene);
    el.addEventListener('change', drawScene);
  });

  let resizeTimer = null;
  window.addEventListener('resize', ()=>{
    clearTimeout(resizeTimer);
    resizeTimer = setTimeout(()=>{ resizeCanvas(); drawScene(); }, 80);
  });

  resizeCanvas();
  drawScene();
})();
</script>
</body>
</html>

```

**사용법**: 위 코드를 Gemini Canvas(또는 캔버스 지원 환경)에 붙여넣으면 즉시 실행됩니다. 조사 활동 전 동기 유발용으로 짧게 보여주거나, 조사·토의를 마친 뒤 "우리가 조사한 사례들이 사실은 이렇게 연결되어 있었다"는 정리 활동으로 활용하면 좋습니다. (그림은 실제 관측 자료의 경향을 반영한 단순화된 표현이며, 정밀한 과학적 예측 모델은 아니라는 점을 학생들에게 안내해 주세요.) 모바일 세로 화면에서도 잘 보이도록 반응형으로 제작했습니다.
