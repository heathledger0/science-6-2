# 6학년 2학기 과학 4단원 「과학과 나의 진로」— (3~4차시) 미래 사회의 문제를 과학이 해결할 수 있을까?

> **안내**: 이 자료는 업로드해 주신 **4단원 지도서(348~357쪽, 「과학」86~87쪽, 「실험관찰」54~55쪽)**를 근거로 작성했습니다. 2차시에서 찾은 미래 사회 문제(인구·환경·윤리)에 이어, 이 차시는 **"그래서 과학이 뭘 할 수 있는데?"**에 답하는 차시입니다. 지도서는 이 차시를 **직소(전문가-시민) 토의**, 또는 **과학-기술-사회(STS) 학습 모형**으로 운영할 수 있다고 안내합니다.

---

## 1. 📖 핵심 개념 상세 정리

### 학습 목표
- 미래 사회의 문제를 해결하는 데 과학이 기여하는 방법을 토의하여 설명할 수 있다. *(지식·이해, 과정·기능, 가치·태도)*
- 성취기준 **[6과16-01]** 미래 사회에 일어날 수 있는 문제를 조사하고, 문제를 해결하는 데 과학이 기여할 수 있는 방법을 토의할 수 있다.

### 핵심 개념 (6학년 눈높이 설명)
- 과학은 현재 일어나고 있는 여러 문제를 해결하는 데 도움을 줄 수 있습니다. 미래에 일어날 수 있는 문제도 마찬가지입니다.
- 2차시에서 찾은 세 가지 문제에 과학이 기여할 수 있는 방법(교과서 제시):
  - **인구 문제(노동력 부족)** → 로봇 기술과 인공지능 기술을 활용한 자동화로 해결
  - **환경 문제(기후 위기·환경오염)** → 친환경적인 재생 에너지(태양광, 풍력 등)를 생산하는 기술로 해결
  - **윤리 문제(사이버 범죄 등)** → 정보 보안 기술의 발전으로 개인 정보 유출·해킹 같은 범죄를 예방
- **그러나!** 미래 사회에 일어날 수 있는 모든 문제를 과학만으로 해결하는 데는 **한계**가 있습니다. 인간의 행복, 삶의 질 같은 문제는 과학만으로 해결할 수 없어 **윤리적·문화적 요소 등을 포함하는 다양한 측면에서 종합적으로 고려**해야 합니다.
- 이렇게 "과학이 모든 문제를 해결할 수 있다"고 믿는 사고방식을 **과학만능주의**라고 하며, 이는 교과서가 명시적으로 경계하는 오개념입니다.

### 🗣️ 설명 스크립트 예시 (도입부 활용)
> "환경오염 문제를 어떻게 해결할 수 있을까요? 쓰레기를 줄이고 재활용하는 것도 방법이지만, 과학은 어떤 도움을 줄 수 있을까요? 오늘은 모둠별로 인구·환경·윤리 문제 중 하나를 맡아서, 과학이 그 문제를 해결하는 데 어떻게 기여할 수 있을지 깊이 토의해 볼 거예요. 그리고 마지막에는 '과학이 정말 모든 걸 다 해결해 줄 수 있을까?'라는 질문도 함께 생각해 볼 거예요."

## 2. 🔎 탐구 활동 완벽 가이드 — 미래 사회의 문제 해결에 과학이 기여하는 방법 토의하기

### 활동 목표
- 미래 사회의 문제 해결에 과학이 기여하는 방법을 토의할 수 있다.

### 준비물
| 준비물 | 비고 |
|---|---|
| 화이트보드, 칠판 펜, 칠판지우개(모둠별) | 전지로 대체 가능 |
| 스마트 기기(개인별) | 조사용 |

### 활동 단계 — 직소(전문가-시민) 토의
1. **도입**: "환경오염 문제를 어떻게 해결할 수 있을까요?"로 이야기를 열고, 과학이 기여할 수 있는 방법을 함께 생각해 봅니다.
2. **모둠별 문제 선택**: 모둠별로 미래 사회에 일어날 수 있는 문제(인구/환경/윤리)를 한 가지 고릅니다. (학급 전체가 세 문제를 골고루 다룰 수 있도록 겹치지 않게 배정합니다.)
3. **1차 토의**: 선택한 문제를 해결하는 데 과학이 기여할 수 있는 방법을 모둠에서 토의하고, 화이트보드에 정리합니다.
4. **역할 분담**: 모둠원 중 절반은 **'문제 해결 전문가'**가 되어 자리에 남고, 나머지 절반은 **'시민'**이 되어 다른 모둠으로 이동합니다.
5. **2차 토의(교차 토의)**: '문제 해결 전문가'는 다른 모둠에서 온 '시민'과 의견을 나눕니다. 토의가 끝나면 '시민'은 다음 모둠으로 이동합니다. 모든 모둠을 다 돌고 나면 '시민'과 '문제 해결 전문가'가 역할을 바꾸어 다시 진행합니다.
6. **[시뮬레이터 활동] 미래 도시 설계하기**: 이 차시의 시뮬레이터로 환경·인구·윤리 문제를 해결하는 과학 기술을 하나씩 우리 도시에 적용해 보고, 모든 기술을 적용한 뒤 "이것으로 충분할까?"라는 질문에 답해 봅니다.
7. **정리해요**: 미래 사회의 문제별로 과학이 기여할 수 있는 방법을 이야기하고, 마지막으로 **"미래 사회의 모든 문제를 과학만으로 해결할 수 있을까?"**를 토의하며 과학의 가치와 한계를 함께 정리합니다.

### 🧭 대체 탐구 — 30년 뒤 미래 도시 설계하기
- 모둠별로 미래 사회의 문제가 적힌 종이를 한 개 골라, 그 문제를 해결하기 위한 자료를 조사하고 과학적인 해결 방안을 토의합니다.
- 과학적인 해결 방안이 반영된 미래 도시를 설계하여(입체 또는 평면) 발표합니다.
- **디지털 활용**: 5대 국립과학관 온라인 특별 전시(vr.science.go.kr)에서 '디지털 플래닛', '탄소C그널', '탄소 2050 제로 시티' 같은 전시를 살펴보며 미래 과학 기술을 체험하고, 그 기술이 미래 사회의 문제를 해결하는 데 어떻게 기여할 수 있을지 생각해 봅니다.

### ⚠️ 유의사항
- 미래 사회의 문제를 해결하는 방법은 다양한 측면에서 접근할 수 있으나, 이 차시에서는 **과학이 기여할 수 있는 해결 방법만** 다루도록 범위를 한정합니다.
- 문제의 원인을 줄이거나 이미 발생한 문제에 대응하는 방식 모두 "과학이 기여하는 방법"으로 인정합니다.
- 미래 사회의 문제를 해결하는 데 **과학의 유용성을 깨닫도록 하되, 과학만으로 모든 문제를 해결할 수 없음을 반드시 함께 지도**합니다.

## 3. 🛡️ 오개념 철벽 방어

### 오개념 1 — "과학만능주의": 과학이 모든 문제를 해결할 수 있다 *(이 차시의 핵심 오개념 — 교과서가 직접 명시)*
- **왜 틀렸나**: 과학 기술을 발전시켜 미래 사회의 문제를 해결하는 데 기여할 수 있지만, **모든 미래 사회의 문제를 과학만으로 해결할 수는 없습니다.** 예를 들어 유전자를 편집해 유전병을 치료하는 기술은 인간에게 유용하게 활용될 수 있지만, 인간의 존엄성을 침해하거나 차별을 초래할 우려가 있어 윤리적 문제가 발생할 수 있습니다.
- **바로잡기**: 윤리적·문화적 문제 등은 과학만으로 해결하기 어렵기 때문에, 다양한 측면에서 종합적으로 고려해 문제를 해결하려는 자세를 지녀야 합니다.
- **교정 발문**: "시뮬레이터에서 미래 도시에 과학 기술 5개를 모두 적용했어요. 그럼 이제 이 도시에는 문제가 하나도 없을까요? 사람들 사이의 다툼이나 가치관 차이도 과학 기술로 해결될까요?"

### 오개념 2 — "환경오염처럼 큰 문제는 과학자가 아니면 해결에 기여할 수 없다"
- **왜 틀렸나**: 과학이 기여하는 방법에는 재생 에너지 기술 개발처럼 전문적인 것도 있지만, 위성·드론·센서로 환경오염을 관측하는 것, 개인정보 보호를 위한 정보 보안 기술 발전처럼 다양한 방식이 있습니다. 또한 생활 속 실천(2단원 8~9차시에서 다룬 내용)과 과학 기술이 함께 어우러질 때 더 큰 효과를 냅니다.
- **교정 발문**: "친환경 재생 에너지를 만드는 것도 과학이 기여하는 방법이지만, 우리가 생활 속에서 전기를 아껴 쓰는 것도 어떤 면에서는 '과학적 지식을 실천하는 것'이라고 할 수 있지 않을까요?"

## 4. 💡 호기심 천국 & 심화 탐구 (영재 교육 연계)

- **과학이 사회 문제를 해결한 역사적 사례**: 천연두는 한때 치명적인 질병이었지만, 백신을 개발해 천연두를 예방함으로써 질병 문제 해결에 크게 기여했습니다. 농업 생산 기술의 발달도 식량 부족 문제를 해결하는 데 기여했습니다.
- **온실가스종합정보센터(gir.go.kr)**: 온실가스 배출 감축 및 기후변화 대응과 관련된 실제 정보와 자료를 살펴볼 수 있습니다.
- **참고 도서**: 박영숙·제롬 글렌, 『10대를 위한 세계 미래 보고서 2035-2055: 기술편』(교보문고, 2021) — 미래 사회의 과학 기술에 관해 더 알아볼 수 있습니다.
- **생각해 볼 질문(영재 학급용)**: "유전자 편집 기술처럼, '과학적으로는 가능하지만 윤리적으로는 신중해야 하는' 기술에는 또 어떤 것이 있을까요? 과학자들은 이런 기술을 개발할 때 어떤 점을 함께 고려해야 할까요?"

(function(){
  const canvas = document.getElementById('stage');
  const ctx = canvas.getContext('2d');
  let W = 900, H = 675;

  function resizeCanvas(){
    const rect = canvas.getBoundingClientRect();
    const dpr = window.devicePixelRatio || 1;
    W = rect.width; H = rect.height;
    canvas.width = Math.max(1, Math.round(W*dpr));
    canvas.height = Math.max(1, Math.round(H*dpr));
    ctx.setTransform(dpr,0,0,dpr,0,0);
  }

  const items = [
    { id:'solar', label:'태양광 지붕', tag:'환경', group:'env', emoji:'☀️' },
    { id:'wind', label:'풍력 발전기', tag:'환경', group:'env', emoji:'💨' },
    { id:'forest', label:'도시 숲', tag:'환경', group:'env', emoji:'🌳' },
    { id:'robot', label:'로봇 자동화 공장', tag:'인구', group:'pop', emoji:'🤖' },
    { id:'security', label:'정보 보안 센터', tag:'윤리', group:'eth', emoji:'🔒' },
  ];
  const state = {};
  items.forEach(i => state[i.id] = false);

  const chipsEnv = document.getElementById('chipsEnv');
  const chipsPop = document.getElementById('chipsPop');
  const chipsEth = document.getElementById('chipsEth');
  const progressNum = document.getElementById('progressNum');
  const progressFill = document.getElementById('progressFill');
  const warnBox = document.getElementById('warnBox');

  items.forEach(item => {
    const chip = document.createElement('button');
    chip.type = 'button';
    chip.className = 'chip';
    chip.innerHTML = `<span>${item.emoji}</span><span>${item.label}</span><span class="tag">#${item.tag}</span>`;
    chip.setAttribute('aria-pressed', 'false');
    chip.addEventListener('click', () => {
      state[item.id] = !state[item.id];
      chip.classList.toggle('sel', state[item.id]);
      chip.setAttribute('aria-pressed', String(state[item.id]));
      render();
    });
    (item.group === 'env' ? chipsEnv : item.group === 'pop' ? chipsPop : chipsEth).appendChild(chip);
  });

  function drawCity(){
    ctx.clearRect(0,0,W,H);
    const skyGrad = ctx.createLinearGradient(0,0,0,H*0.62);
    skyGrad.addColorStop(0, '#bfe0f7');
    skyGrad.addColorStop(1, '#eaf5fb');
    ctx.fillStyle = skyGrad;
    ctx.fillRect(0,0,W,H*0.64);

    ctx.fillStyle = '#d8cf9e';
    ctx.fillRect(0, H*0.62, W, H*0.38);

    // 해
    ctx.fillStyle = '#f4c968';
    ctx.beginPath(); ctx.arc(W*0.86, H*0.14, W*0.045, 0, Math.PI*2); ctx.fill();

    // 풍력 발전기(배경, 토글)
    if(state.wind){
      [0.1, 0.18].forEach((px, i) => {
        const bx = W*px, by = H*0.58, bladeLen = W*0.055;
        ctx.strokeStyle = '#8a8578';
        ctx.lineWidth = Math.max(2, W*0.007);
        ctx.beginPath(); ctx.moveTo(bx, by); ctx.lineTo(bx, by-H*0.26); ctx.stroke();
        ctx.save();
        ctx.translate(bx, by-H*0.26);
        ctx.rotate((i*0.5) + 0.3);
        ctx.strokeStyle = '#f5f5f0';
        ctx.lineWidth = Math.max(2.5, W*0.009);
        for(let k=0;k<3;k++){
          ctx.save();
          ctx.rotate(k*2.094);
          ctx.beginPath(); ctx.moveTo(0,0); ctx.lineTo(0,-bladeLen); ctx.stroke();
          ctx.restore();
        }
        ctx.restore();
      });
    }

    // 도시 숲(토글)
    if(state.forest){
      [0.04,0.08,0.92,0.96].forEach(px => {
        const tx = W*px, ty = H*0.64;
        ctx.fillStyle = '#4a8a5c';
        for(let s=0;s<3;s++){
          const segH = H*0.05, segY = ty - s*segH*0.6, segW = W*0.028*(1-s*0.2);
          ctx.beginPath();
          ctx.moveTo(tx, segY-segH); ctx.lineTo(tx-segW, segY); ctx.lineTo(tx+segW, segY); ctx.closePath(); ctx.fill();
        }
      });
    }

    // 집 3채(기본)
    const houseXs = [0.28, 0.46, 0.64];

      ctx.fillStyle = '#bfe3ff';
      ctx.fillRect(hx+hw*0.18, hy+hh*0.3, hw*0.22, hh*0.3);
      ctx.fillRect(hx+hw*0.6, hy+hh*0.3, hw*0.22, hh*0.3);

      // 태양광 지붕(토글)
      if(state.solar){

        const px0 = hx-W*0.005, py0 = hy-H*0.045;

        ctx.beginPath();
        ctx.moveTo(px0, py0+H*0.012);
        ctx.lineTo(hx+hw/2, hy-H*0.05);
        ctx.lineTo(hx+hw+W*0.005, py0+H*0.012);
        ctx.lineTo(hx+hw*0.82, hy-H*0.005);
        ctx.lineTo(hx+hw*0.18, hy-H*0.005);
        ctx.closePath();
        ctx.fill();
        ctx.restore();
      }
    });

    // 로봇 자동화 공장(토글)
    if(state.robot){
      const fx = W*0.1, fy = H*0.62-H*0.2, fw = W*0.14, fh = H*0.2;
      ctx.fillStyle = '#c9c2ac';
      ctx.fillRect(fx, fy, fw, fh);
      ctx.fillStyle = '#8a8578';
      ctx.fillRect(fx+fw*0.1, fy-H*0.05, fw*0.14, H*0.05);
      ctx.beginPath(); ctx.arc(fx+fw*0.17, fy-H*0.055, W*0.012, 0, Math.PI*2); ctx.fillStyle='#d9432b'; ctx.fill();
      ctx.font = 'bold ' + (W*0.05).toFixed(1) + 'px sans-serif';
      ctx.textAlign = 'center';
      ctx.fillText('🤖', fx+fw/2, fy+fh*0.65);
    }

    // 정보 보안 센터(토글)
    if(state.security){
      const sx = W*0.78, sy = H*0.62-H*0.17, sw = W*0.14, sh = H*0.17;
      ctx.fillStyle = '#e3e8f0';
      ctx.fillRect(sx, sy, sw, sh);
      ctx.strokeStyle = '#2f5fa8';
      ctx.lineWidth = 2;
      ctx.strokeRect(sx, sy, sw, sh);
      ctx.font = 'bold ' + (W*0.05).toFixed(1) + 'px sans-serif';
      ctx.textAlign = 'center';
      ctx.fillText('🔒', sx+sw/2, sy+sh*0.65);
    }

    ctx.fillStyle = '#3a3226';
    ctx.font = 'bold ' + (W*0.04).toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText('우리가 설계하는 30년 뒤 미래 도시', W/2, H*0.1);
  }

  function render(){
    drawCity();
    const n = items.filter(i => state[i.id]).length;
    progressNum.textContent = `적용한 과학 기술 ${n} / ${items.length}`;
    progressFill.style.width = (n/items.length*100) + '%';
    warnBox.classList.toggle('show', n === items.length);
  }

  let resizeTimer = null;
  window.addEventListener('resize', () => {
    clearTimeout(resizeTimer);
    resizeTimer = setTimeout(() => { resizeCanvas(); render(); }, 80);
  });

  resizeCanvas();
  render();
})();
