# 6학년 2학기 과학 4단원 「과학과 나의 진로」— (6~7차시) 나의 진로는 과학과 어떤 관련이 있을까?

> **안내**: 이 자료는 업로드해 주신 **4단원 지도서(368~379쪽, 「과학」92~95쪽, 「실험관찰」58~59쪽)**를 근거로 작성했습니다. 5차시에서 "모든 직업은 과학과 관련 있다"는 것을 발견했다면, 이 차시는 그것을 **"그렇다면 나는?"** 이라는 질문으로 개인화하는 단원의 클라이맥스 차시입니다. 「실험관찰」 81쪽의 '올해의 인물' 기사문 양식을 활용해 20년 뒤 나의 모습을 기사로 작성하는 활동이 핵심입니다.

---

## 1. 📖 핵심 개념 상세 정리

### 학습 목표
- 나의 진로를 과학과 관련지어 설명할 수 있다. *(지식·이해, 가치·태도)*
- 진로와 관련 있는 과학적 요소를 탐구할 수 있다. *(과정·기능)*
- 성취기준 **[6과16-02]** 다양한 진로가 과학과 관련됨을 알고, 자신의 진로를 과학과 관련지어 설명할 수 있다. (탐구 활동: 우리의 진로에 영향을 미치는 과학적 요소 탐구하기)

### 핵심 개념 (6학년 눈높이 설명)
- 과학 기술의 발달은 사회 모습뿐 아니라 **진로에도 변화**를 가져옵니다. 예를 들어 확장 현실(VR·AR) 기술, 센서 기술, 개인 맞춤형 비서 로봇 같은 미래 과학 기술은 스마트 의류 개발자 같은 새로운 진로를 가능하게 합니다.
- 5차시에서 배운 것처럼, 나의 진로와 관련된 과학적 요소도 **① 과학 지식**과 **② 과학적 탐구 과정**으로 나누어 생각할 수 있습니다.
  - 예(우주 비행사): 과학 지식 — 태양계와 행성, 별의 특징 / 과학적 탐구 과정 — 우주 정거장에서 태양계를 관측해 자료를 수집하고 탐사를 계획·실천하는 과정
  - 예(스마트 의류 개발자): 과학 지식 — 우리 몸의 구조와 기능, 신체 변화 / 과학적 탐구 과정 — 센서 기술을 활용해 신체 변화를 감지하는 스마트 의류를 개발하고 실험하는 과정
- 과학 기술의 발달이 가져올 미래 사회의 모습에 맞춰 나의 진로를 과학과 관련지어 생각해 보면, 막연했던 꿈이 좀 더 구체적인 계획으로 바뀝니다.

### 🗣️ 설명 스크립트 예시 (도입부 활용)
> "20년 뒤, 여러분은 어떤 일을 하고 있을까요? 오늘은 그 미래의 나를 그냥 상상만 하는 게 아니라, '그 일을 하려면 어떤 과학을 알아야 할까?'까지 구체적으로 생각해 볼 거예요. 그리고 마지막엔, 20년 뒤 성공한 나를 다룬 신문 기사를 직접 만들어 볼 거예요!"

## 2. 🔎 탐구 활동 완벽 가이드 — 우리의 진로에 영향을 미치는 과학적 요소 탐구하기

### 활동 목표
- 나의 진로를 과학과 관련지어 설명할 수 있다.

### 준비물
| 준비물 | 비고 |
|---|---|
| 스마트 기기(개인별) | 미래 과학 기술 조사용 |
| '올해의 인물' 기사문 양식 (『실험관찰』 81쪽) | 도화지나 A4 용지로 대체 가능 |

### 활동 단계
1. **내가 하고 싶은 일 이야기하기**: 미래에 하고 싶은 일을 자유롭게 이야기합니다.
2. **관련 과학 기술 조사하기**: 내가 하고 싶은 일과 관련된 미래의 과학 기술을 조사하고, 나의 진로에 어떤 영향을 미칠지 이야기합니다. (예: 우주 비행사 → 항공 우주 기술, 인공지능 기술)
3. **[탐구 활동] 과학적 요소 탐구하기**: 나의 진로와 관련된 과학적 요소를 과학 지식과 과학적 탐구 과정으로 나누어 이야기합니다.
4. **진로 목표 세우기**: 진로 목표를 세우고, 나의 진로 계획을 이야기합니다.
5. **[시뮬레이터 활동] 기사문 작성하기**: 기사문 양식을 이용해 20년 뒤 나의 모습을 다룬 기사를 작성합니다. 이 차시의 시뮬레이터로 빈칸을 채우면 기사 형식으로 자동 완성됩니다.
6. **체험 더하기**: 한국잡월드(koreajobworld.or.kr)의 청소년체험관·숙련기술체험관·진로설계관이나 어린이 메타버스 앱으로 다양한 직업을 체험하고 진로와 과학의 관련성을 더 탐구해 봅니다.

### ⚠️ 유의사항
- 이전 차시 '3. 다양한 진로가 과학과 관련됨을 알아볼까?'에서 학습한 **직업과 관련된 과학적 요소를 학생 자신의 진로에 적용**하는 차시입니다. 학생이 어려워하면 이전 차시 학습을 상기시키거나 다양한 예시를 들어 설명해 줍니다.
- 과학 기술의 발달이 진로에 어떤 영향을 미치는지 사례를 들어 설명함으로써 학생들의 이해를 돕습니다.
- 스마트 기기를 사용할 때 유해 사이트에 접속하지 않도록 지도합니다.

## 3. 🛡️ 오개념 철벽 방어

### 오개념 1 — "나의 꿈과 과학은 상관없다" (내가 과학자가 되고 싶은 게 아니라면)
- **왜 틀렸나**: 5차시에서 확인했듯, 거의 모든 직업에는 과학 지식과 과학적 탐구 과정이 숨어 있습니다. 심지어 "과학과 거리가 멀다"고 생각하기 쉬운 스마트 의류 개발자 같은 직업도 사실은 신체 공학, 센서 기술 등 깊은 과학적 기반 위에 서 있습니다.
- **교정 발문**: "네가 꿈꾸는 일이 무엇이든, 그 일을 아주 잘하는 사람이 되려면 어떤 과학을 알아야 할지 한번 찾아볼까?"

### 오개념 2 — "진로 계획은 지금 당장 확실하게 정해야 한다"
- **왜 틀렸나**: 이 차시의 목적은 "평생 지킬 확정된 꿈"을 강요하는 것이 아니라, **과학이라는 렌즈로 미래를 그려보는 연습**을 하는 것입니다. 지도서도 "학생이 과학적 요소를 찾는 것을 어려워하는 경우 다양한 예시를 들어 설명한다"고 안내할 뿐, 진로를 평가하거나 확정 짓지 않습니다.
- **교정 발문**: "오늘 적은 미래의 꿈이 평생 바뀌지 않아야 할까요, 아니면 지금은 과학적으로 꿈을 그려보는 연습을 하는 걸까요?"

## 4. 💡 호기심 천국 & 심화 탐구 (영재 교육 연계)

- **진로 탐색 사이트 활용**: 커리어넷(career.go.kr)에서는 직업 정보 검색과 함께 **진로 심리 검사**도 해볼 수 있습니다. 주니어 커리어넷(career.go.kr/jr)에서는 진로 흥미 탐색과 다양한 직업 소개 자료를, 서울진로진학정보센터(jinhak.or.kr)에서는 다양한 직업인의 이야기를 찾아볼 수 있습니다.
- **한국잡월드 심화 체험**: 숙련기술체험관에서는 전통 기술, 제조 산업 기술, 첨단 기술 등 다양한 과학 기술을 체험하고 4차 산업 시대의 직업을 미리 경험할 수 있습니다. 한국잡월드 어린이 메타버스 앱으로는 실제 직업 환경을 모방한 가상 공간에서 업무 과정을 체험할 수도 있습니다.
- **생각해 볼 질문(영재 학급용)**: "내가 꿈꾸는 직업이 10~11차시에서 배운 인공지능 때문에 크게 바뀐다면, 그때도 변하지 않을 '내가 그 일을 통해 이루고 싶은 목표'는 무엇일까요?" (직업(하는 일)과 진로(삶의 방향)의 차이를 스스로 구분해 보게 하는 질문입니다.)

(function(){
  const techs = ['인공지능','로봇 공학','항공 우주 기술','센서 기술','확장 현실(VR·AR)','생명 공학','신재생 에너지','빅데이터'];

  const techChips = document.getElementById('techChips');
  techs.forEach(t => {
    const chip = document.createElement('button');
    chip.type = 'button';
    chip.className = 'chip';
    chip.textContent = t;
    chip.setAttribute('aria-pressed','false');
    chip.addEventListener('click', () => {
      if(selected.has(t)){ selected.delete(t); chip.classList.remove('sel'); chip.setAttribute('aria-pressed','false'); }
      else { selected.add(t); chip.classList.add('sel'); chip.setAttribute('aria-pressed','true'); }
    });
    techChips.appendChild(chip);
  });

  const inName = document.getElementById('inName');
  const inJob = document.getElementById('inJob');
  const inGoal = document.getElementById('inGoal');
  const inKnow = document.getElementById('inKnow');
  const inInquiry = document.getElementById('inInquiry');
  const genBtn = document.getElementById('genBtn');
  const news = document.getElementById('news');

  function esc(s){
    const d = document.createElement('div');
    d.textContent = s;
    return d.innerHTML;
  }

  function punct(s){
    s = s.trim();
    if(!s) return s;
    return /[.!?다요]$/.test(s) ? s : s + '.';
  }

  genBtn.addEventListener('click', () => {
    const name = (inName.value || '이름 없는 과학자').trim();
    const job = (inJob.value || '미래의 전문가').trim();
    const goal = (inGoal.value || '사람들에게 도움이 되는 일').trim();
    const know = (inKnow.value || '').trim();
    const inquiry = (inInquiry.value || '').trim();
    const techList = Array.from(selected);
    const year = new Date().getFullYear() + 20;

    document.getElementById('newsTitle').textContent = `${name}, 꿈이었던 '${job}'이 되다`;
    document.getElementById('newsDate').textContent = `${year}년 · 과학과 나의 진로 특집`;

    let body = `${year}년 올해의 인물로 <b>${esc(name)}</b> 씨가 선정되었다. ${esc(name)} 씨는 어린 시절 꿈꾸던 <b>${esc(job)}</b>이 되어, ${esc(goal)}을 하고 있다.`;
    if(techList.length){
      body += ` ${esc(name)} 씨가 이 꿈을 이루는 데에는 <b>${techList.map(esc).join(', ')}</b> 기술이 큰 역할을 했다.`;
    }
    if(know){
      body += `<br><br>${esc(name)} 씨는 이렇게 말했다. "이 일을 하려면 이런 과학 지식이 필요해요 — <b>${esc(punct(know))}</b>`;

    }
    if(know || inquiry){
      body += ` 과학은 제 꿈을 이루는 데 정말 큰 도움이 되었습니다."`;
    }
    body += `<br><br>${esc(name)} 씨는 "앞으로도 과학과 함께 꿈을 넓혀 가고 싶다"는 포부를 밝혔다.`;

    document.getElementById('newsBody').innerHTML = body;

    const tagsEl = document.getElementById('newsTags');

    ['#' + job, ...techList.map(t => '#' + t)].forEach(tag => {

      tagsEl.appendChild(span);
