# 6학년 2학기 과학 1단원 「계절의 변화」— (8차시) 계절 변화의 원인을 찾아라!

> **안내**: 이 자료는 2022 개정 교육과정 6학년 2학기 과학 1단원 「계절의 변화」의 표준 학습 흐름에 맞추어 작성했습니다. 앞선 세 차시(1차시 「태양 고도 측정기를 만들자」, 5~6차시 「남중고도와 낮의 길이」, 7차시 「태양 고도와 태양 에너지양의 관계」)에서 쌓아 온 개념 — 태양 고도 측정법, 계절별 남중고도·낮의 길이 변화, 태양 고도와 에너지의 관계 — 을 이 차시에서 하나로 묶어 "계절이 왜 생기는가"라는 단원 전체의 핵심 질문에 답하도록 구성했습니다. 이 차시가 사실상 1단원의 결론에 해당합니다.
> 혹시 선생님께서 가지고 계신 **지도서·진도표 원문(쪽수, 교과서 페이지)**을 공유해 주시면, 다음 업데이트 때 정확한 쪽수 인용까지 맞춰 반영해 드리겠습니다.

## 1. 📖 핵심 개념 상세 정리

### 학습 목표
- 지구의 자전축이 기울어진 채 태양 주위를 공전하기 때문에 계절에 따라 태양의 남중 고도가 달라짐을 모형실험으로 설명할 수 있다. *(지식·이해, 과정·기능)*
- 태양의 남중 고도 변화가 태양 에너지양·기온 변화로 이어져 계절이 생긴다는 것을 지금까지 배운 내용과 연결지어 설명할 수 있다. *(지식·이해, 과정·기능)*

### 핵심 개념 (6학년 눈높이 설명)
- 지구는 자전축이 수직에서 **23.5° 기울어진 채** 태양 주위를 1년에 한 바퀴 공전합니다.
- 이 자전축은 지구가 궤도의 어느 위치에 있든 **항상 같은 방향(우주의 한 점, 대략 북극성 방향)을 가리킵니다.** 방향이 바뀌지 않고 평행하게 이동만 합니다.
- 이 때문에 지구가 공전하면서 **북반구가 태양 쪽으로 기우는 시기(여름)**와 **태양 반대쪽으로 기우는 시기(겨울)**가 번갈아 생깁니다.
- 북반구가 태양 쪽으로 기울면 → 태양의 **남중 고도가 높아지고** → (7차시에서 배운 대로) **좁은 면적에 에너지가 집중**되어 → **기온이 높아짐(여름)**.
- 북반구가 태양 반대쪽으로 기울면 → 남중 고도가 **낮아지고** → 에너지가 **넓게 퍼져** → **기온이 낮아짐(겨울)**.
- 정리하면, **계절 변화의 원인 = 지구 자전축의 기울어짐 + 지구의 공전.** 둘 중 하나라도 없으면 계절은 생기지 않습니다(아래 오개념 2 참고).

### 🗣️ 설명 스크립트 예시 (도입부 활용)
> "우리는 1차시부터 태양의 높이(고도)를 재는 법을 배우고, 계절마다 남중고도와 낮의 길이가 다르다는 것을 확인했고, 지난 시간엔 태양 고도가 높을수록 에너지가 더 세게 집중된다는 것도 확인했어요. 그런데 정작 '왜' 계절마다 태양의 높이 자체가 달라지는지는 아직 답하지 않았죠? 오늘은 이 단원의 마지막 퍼즐 조각, **계절이 생기는 진짜 원인**을 지구본과 전등으로 직접 실험하며 찾아볼 거예요."

## 2. 🧪 실험 완벽 가이드 — 지구본과 전등으로 계절 변화의 원인 찾기

### 실험 목표
- 자전축이 기울어진 지구본을 전등(태양) 주위로 공전시키며, 위치에 따라 남중 고도가 달라짐을 확인한다.
- 자전축이 기울어지지 않은 지구본으로 같은 실험을 반복해, **기울기가 없으면 공전만으로는 계절이 생기지 않음**을 비교·확인한다.

### 준비물
| 기본 준비물 | 교실 대체 가능 물품 |
|---|---|
| 지구의(자전축이 23.5° 고정으로 기울어진 것) | 스티로폼 공 + 나무젓가락(축), 각도기로 기울기 표시 |
| 전등(스탠드형, 태양 역할) | 손전등 + 삼각대 |
| 각도기 | - |
| 우리나라 위치 스티커(지구의에 부착) | 매직으로 표시 |
| 공전 궤도 표시용 큰 원(바닥에 4~8곳 표시) | 색 테이프로 바닥에 표시 |
| (비교 실험용) 자전축이 수직인 지구본 또는 축 각도 조절이 되는 거치대 | 나무젓가락을 수직으로 꽂은 스티로폼 공 |

### 실험 단계
1. 교실(또는 어두운 공간) 가운데에 전등을 켜서 태양 역할을 하게 합니다.
2. 전등 주위에 지구 공전 궤도를 나타내는 큰 원을 표시하고, **춘분·하지·추분·동지**에 해당하는 네 지점을 표시합니다.
3. 자전축이 기울어진 지구의를 하지 위치에 놓습니다. 이때 **자전축은 항상 같은 방향(예: 교실의 특정 벽 쪽)을 가리키도록** 유지합니다.
4. 지구의에 표시된 우리나라 위치에서, 전등 빛이 남중할 때의 고도를 각도기로 측정하고 기록합니다.
5. 지구의를 자전축 방향은 그대로 유지한 채 추분 → 동지 → 춘분 위치로 차례로 옮기며, 각 위치에서 같은 방법으로 남중 고도를 측정·기록합니다.
6. 네 지점의 측정값을 표로 정리하고 비교합니다 — 하지에서 가장 높고 동지에서 가장 낮으며, 춘분·추분은 그 중간(같은 값)임을 확인합니다.
7. **(핵심 비교 실험)** 이번엔 **자전축이 기울어지지 않은(수직인) 지구의**로 3~6번을 반복합니다. → 네 지점 모두 남중 고도가 **거의 같게** 측정됨을 확인합니다.
8. **토의**: "두 실험에서 지구가 태양 주위를 도는 것(공전)은 똑같았는데, 왜 한쪽만 계절에 따라 고도가 달라졌을까요?" → 자전축이 기울어져 있어야만 공전이 계절 변화로 이어진다는 결론을 이끌어냅니다.

> 모둠별로 네 지점을 나눠 맡아 동시에 측정한 뒤 칠판에 모으면 시간을 절약할 수 있습니다. 실제 태양 대신 전등을 쓰므로 그림자나 남중 판단이 애매할 수 있는데, 지구의 위 우리나라 표시에 작은 막대(수수깡)를 수직으로 꽂아 1차시의 원리대로 그림자가 가장 짧아지는 순간을 남중으로 판단하면 정확도가 올라갑니다.

### ⚠️ 안전 유의사항
- **전등이 뜨거울 수 있으므로** 백열등·할로겐등을 사용할 경우 직접 만지지 않도록 지도합니다.
- 교실을 어둡게 하고 이동하므로 **책상·의자에 걸려 넘어지지 않도록** 사전에 동선을 정리합니다.
- 지구의를 돌리거나 옮길 때 옆 친구와 부딪히지 않도록 모둠 내 역할(고정 담당/측정 담당/기록 담당)을 나눠 진행합니다.

## 3. 🛡️ 오개념 철벽 방어

### 오개념 1 — "지구가 태양에 가까워지고 멀어져서 계절이 바뀐다" *(단원 전체에서 가장 뿌리 깊은 오개념 — 이 차시에서 완전히 종식시켜야 함)*
- **왜 틀렸나**: 지구의 공전 궤도는 거의 원에 가까워 태양과의 거리 차이가 계절에 거의 영향을 주지 않습니다. 오히려 북반구가 여름인 7월에 지구는 태양에서 **더 멀고**, 겨울인 1월에 **더 가깝습니다.** 계절을 만드는 진짜 원인은 거리가 아니라 **자전축이 기울어진 채 공전하며 생기는 남중 고도 변화**입니다.
- **교정 발문**: "만약 거리 때문에 계절이 바뀐다면 북반구와 남반구가 같은 시기에 같은 계절이어야 하지 않을까요? 그런데 우리나라가 여름일 때 호주는 겨울이에요. 지구와 태양 사이의 거리는 북반구든 남반구든 똑같은데, 왜 계절이 반대일까요?" (7차시에서 이미 소개한 오개념이지만, 이번 차시의 모형실험으로 결정적으로 반박할 수 있습니다.)

### 오개념 2 — "지구가 자전축 없이 공전만 해도 계절이 생긴다"
- **왜 틀렸나**: 위 실험 7번에서 직접 확인했듯, 자전축이 수직이면(기울어지지 않으면) 지구가 아무리 공전해도 남중 고도가 전혀 바뀌지 않습니다. **공전은 계절 변화의 필요조건이지만, 자전축의 기울어짐이 있어야만 공전이 실제로 계절 변화를 만들어냅니다.**
- **교정 발문**: "이 시뮬레이터에서 '자전축 기울기 없이 비교하기'를 켜면 지구를 아무리 돌려도 왜 남중 고도 숫자가 그대로일까요?"

### 오개념 3 — "지구가 공전하면서 자전축의 기울어진 방향도 계속 바뀐다"
- **왜 틀렸나**: 실제로는 자전축의 방향은 1년 동안(사실은 아주 오랜 시간 동안) 거의 일정하게 유지됩니다(아주 느린 '세차운동'으로 아주 조금씩만 바뀌며, 그 주기는 약 26,000년입니다). 자전축의 **방향이 고정되어 있기 때문에** 지구가 공전 궤도의 반대편으로 이동하면 반대쪽 반구가 태양을 향하게 되는 것입니다.
- **교정 발문**: "지구의 자전축이 궤도를 따라 움직일 때마다 방향을 이리저리 바꾼다면, 계절이 지금처럼 규칙적으로 반복될 수 있을까요?"

### 오개념 4 — "북반구와 남반구는 같은 시기에 같은 계절을 겪는다"
- **왜 틀렸나**: 자전축의 방향이 고정되어 있으므로, 북반구가 태양 쪽으로 기울어 여름일 때 남반구는 정반대로 태양에서 먼 쪽으로 기울어 겨울입니다. 실제로 호주·뉴질랜드 등 남반구 국가는 12월에 여름을 보냅니다.
- **교정 발문**: "크리스마스 카드에 눈 내리는 그림이 많은데, 남반구 호주의 크리스마스는 한여름이에요. 왜 그럴까요?"

## 4. 💡 호기심 천국 & 심화 탐구 (영재 교육 연계)

- **다른 행성의 계절**: 화성은 지구와 비슷한 자전축 기울기(약 25°)를 가지고 있어 지구처럼 뚜렷한 사계절이 있습니다. 반면 목성은 자전축이 거의 기울지 않아(약 3°) 계절 변화가 거의 없고, **천왕성은 자전축이 거의 98°나 기울어져** 옆으로 누운 채 공전해 한쪽 극이 수십 년간 계속 낮이거나 계속 밤인 극단적인 계절을 겪습니다.
- **세차운동과 미래의 북극성**: 지구 자전축의 방향은 아주 느리게(약 26,000년 주기로) 원을 그리며 돕니다. 지금은 북극성(폴라리스)이 자전축이 가리키는 방향에 가깝지만, 약 12,000년 뒤에는 거문고자리의 베가가 그 자리를 대신하게 됩니다.
- **왜 23.5°일까?**: 과학자들은 지구가 형성되던 초기에 화성 크기의 천체와 충돌하면서(이 충돌로 달이 만들어졌다는 가설도 있습니다) 자전축이 지금처럼 기울어졌을 것으로 추정합니다.
- **극지방의 백야와 극야**: 자전축 기울기가 23.5°이기 때문에, 위도 66.5°(북극권/남극권)보다 높은 지역에서는 여름에 해가 지지 않는 백야, 겨울에 해가 뜨지 않는 극야 현상이 나타납니다. 오늘 배운 원리로 "왜 하필 66.5°일까?"(90°-23.5°)를 스스로 유도해 보게 할 수 있습니다.
- **생각해 볼 질문(영재 학급용)**: "만약 지구의 자전축 기울기가 지금의 23.5°가 아니라 0°였다면 적도와 극지방의 기후는 각각 어떻게 달라질까요? 반대로 45°였다면 어떨까요?"

(function(){
  const canvas = document.getElementById('stage');
  const ctx = canvas.getContext('2d');
  let W = 900, H = 1125;

  function resizeCanvas(){
    const rect = canvas.getBoundingClientRect();
    const dpr = window.devicePixelRatio || 1;
    W = rect.width; H = rect.height;
    canvas.width = Math.max(1, Math.round(W*dpr));
    canvas.height = Math.max(1, Math.round(H*dpr));
    ctx.setTransform(dpr,0,0,dpr,0,0);
  }

  // ---- 레이아웃(모두 W·H 비율로 정의 — 화면 폭이 좁아도 글씨/그림이 작아지지 않게) ----
  let ORBIT_CX, ORBIT_CY, ORBIT_R, ORBIT_BOTTOM, ALT_TOP, ALT_BOTTOM, ALT_X0, ALT_X1;
  let earthR, sunR, titleFont, labelFont, badgeFont;

  function computeLayout(){
    ORBIT_BOTTOM = H*0.56;
    ORBIT_CX = W*0.5; ORBIT_CY = ORBIT_BOTTOM*0.46;
    ORBIT_R = Math.min(W,ORBIT_BOTTOM)*0.36;
    ALT_TOP = H*0.62; ALT_BOTTOM = H*0.97;
    ALT_X0 = W*0.03; ALT_X1 = W*0.97;
    earthR = W*0.028;
    sunR = W*0.05;
    titleFont = W*0.042;
    labelFont = W*0.044;
    badgeFont = W*0.038;
  }

  const LAT = 37.5;      // 우리나라(서울) 기준 위도
  const TILT = 23.5;     // 지구 자전축 기울기(도)
  // 화면상 자전축이 향하는 고정 방향(임의로 정한 뒤, 궤도 위치를 이 방향에 맞춰 일관되게 계산함)
  const axisScreenLean = 25; // 수직에서 오른쪽으로 몇 도 기울어 보이게 그릴지(그림용 각도)
  const axisVec = { x: Math.sin(deg2rad(axisScreenLean)), y: -Math.cos(deg2rad(axisScreenLean)) };
  const axisAngle = Math.atan2(axisVec.y, axisVec.x);
  const summerPhi = axisAngle + Math.PI; // 축이 태양쪽으로 가장 많이 기우는(=여름) 공전 위치

  function deg2rad(d){ return d*Math.PI/180; }
  function rad2deg(r){ return r*180/Math.PI; }
  function clamp(v,a,b){ return Math.max(a, Math.min(b, v)); }

  // 월 -> 태양의 적위(계절에 따라 -23.5°~+23.5°로 변함). 3월(춘분)=0, 6월(하지)=+23.5, 9월(추분)=0, 12월(동지)=-23.5
  function declination(month){ return TILT * Math.sin(deg2rad((month-3)*30)); }
  function altitudeFor(month, tiltOff){
    const decl = tiltOff ? 0 : declination(month);
    return 90 - LAT + decl;
  }
  function energyPct(altDeg){ return Math.max(0, Math.sin(deg2rad(altDeg))) * 100; }
  function seasonName(month){
    const m = ((month-1+12)%12)+1;
    if(m>=3 && m<6) return '봄';
    if(m>=6 && m<9) return '여름';
    if(m>=9 && m<12) return '가을';
    return '겨울';
  }
  // 월 -> 궤도 위 각도(화면 라디안). 자전축이 태양쪽으로 가장 기우는 위치(summerPhi)를 6월로 놓고,
  // 한 달에 30°씩 이동시켜 나머지 달의 위치를 정함 (자전축 방향은 항상 고정!)
  function orbitAngle(month){ return summerPhi + deg2rad((month-6)*30); }

  const monthSlider = document.getElementById('monthSlider');
  const monthVal = document.getElementById('monthVal');
  const noTilt = document.getElementById('noTilt');
  const showAllPos = document.getElementById('showAllPos');
  const seasonOut = document.getElementById('seasonOut');
  const altOut = document.getElementById('altOut');
  const energyOut = document.getElementById('energyOut');
  const altBar = document.getElementById('altBar');
  const energyBar = document.getElementById('energyBar');

  function updateSliderFill(slider){
    const min = parseFloat(slider.min), max = parseFloat(slider.max), v = parseFloat(slider.value);
    slider.style.setProperty('--fill', ((v-min)/(max-min))*100 + '%');
  }

  function drawEarthAt(month, isMain, tiltOff){
    const phi = orbitAngle(month);
    const ex = ORBIT_CX + ORBIT_R*Math.cos(phi);
    const ey = ORBIT_CY + ORBIT_R*Math.sin(phi);
    const r = isMain ? earthR : earthR*0.62;

    // 태양 빛(태양 -> 지구)
    if(isMain){
      ctx.strokeStyle = 'rgba(224,121,15,0.55)';
      ctx.lineWidth = Math.max(1.4, W*0.0026);
      ctx.setLineDash([5,5]);
      ctx.beginPath();
      ctx.moveTo(ORBIT_CX, ORBIT_CY);
      ctx.lineTo(ex, ey);
      ctx.stroke();
      ctx.setLineDash([]);
    }

    // 지구 몸체
    ctx.fillStyle = isMain ? '#5b8fd6' : 'rgba(91,143,214,0.55)';
    ctx.beginPath(); ctx.arc(ex, ey, r, 0, Math.PI*2); ctx.fill();
    ctx.strokeStyle = isMain ? '#2f5fa8' : 'rgba(47,95,168,0.6)';
    ctx.lineWidth = 1.4;
    ctx.stroke();

    // 자전축(기울기 비교 모드면 항상 수직, 아니면 고정 방향 유지)
    const ax = tiltOff ? 0 : axisVec.x;
    const ay = tiltOff ? -1 : axisVec.y;
    const axisLen = r*2.1;
    ctx.strokeStyle = isMain ? '#3f7d54' : 'rgba(63,125,84,0.55)';
    ctx.lineWidth = isMain ? Math.max(2, W*0.0033) : 1.6;
    ctx.beginPath();
    ctx.moveTo(ex-ax*axisLen, ey-ay*axisLen);
    ctx.lineTo(ex+ax*axisLen, ey+ay*axisLen);
    ctx.stroke();

    // 우리나라 위치(북반구, 축의 '북쪽' 방향 쪽에 살짝 치우친 지점)
    const kx = ex + ax*r*0.55 + (-ay)*r*0.35;
    const ky = ey + ay*r*0.55 + (ax)*r*0.35;
    ctx.fillStyle = '#d9432b';
    ctx.beginPath(); ctx.arc(kx, ky, Math.max(2, r*0.24), 0, Math.PI*2); ctx.fill();

    if(isMain){
      ctx.fillStyle = '#3a3226';
      ctx.font = 'bold ' + labelFont.toFixed(1) + 'px sans-serif';
      const seasonLabel = seasonName(month);
      const titleClearance = H*0.045 + labelFont*0.8; // 위쪽 패널 제목과 겹치지 않도록
      const below = ey + r + labelFont*1.3;
      if(below < ORBIT_BOTTOM - labelFont*0.3){
        ctx.textAlign = 'center';
        ctx.fillText(seasonLabel, ex, below);
      } else if(ey - r - labelFont*0.6 > titleClearance){
        ctx.textAlign = 'center';
        ctx.fillText(seasonLabel, ex, ey - r - labelFont*0.6);
      } else {
        ctx.textAlign = ex > ORBIT_CX ? 'left' : 'right';
        ctx.fillText(seasonLabel, ex + (ex > ORBIT_CX ? r*1.4 : -r*1.4), ey + labelFont*0.35);
      }
      ctx.textAlign = 'left';
    }
    return { ex, ey };
  }

  function drawOrbitPanel(month, tiltOff){
    // 궤도
    ctx.strokeStyle = 'rgba(90,70,30,0.28)';
    ctx.lineWidth = 1.4;
    ctx.setLineDash([2,4]);
    ctx.beginPath();
    ctx.arc(ORBIT_CX, ORBIT_CY, ORBIT_R, 0, Math.PI*2);
    ctx.stroke();
    ctx.setLineDash([]);

    // 태양
    const sunGlow = ctx.createRadialGradient(ORBIT_CX,ORBIT_CY,1,ORBIT_CX,ORBIT_CY,sunR*1.8);
    sunGlow.addColorStop(0,'rgba(255,214,120,0.85)');
    sunGlow.addColorStop(1,'rgba(255,214,120,0)');
    ctx.fillStyle = sunGlow;
    ctx.beginPath(); ctx.arc(ORBIT_CX,ORBIT_CY,sunR*1.8,0,Math.PI*2); ctx.fill();
    ctx.fillStyle = '#ffcf5c';
    ctx.beginPath(); ctx.arc(ORBIT_CX,ORBIT_CY,sunR,0,Math.PI*2); ctx.fill();
    ctx.strokeStyle = '#e0790f';
    ctx.lineWidth = 2;
    ctx.stroke();

    // 사계절 참고 위치(옅게)
    if(showAllPos.checked){
      [3,6,9,12].forEach(m=>{
        if(Math.abs(m-month) > 0.2) drawEarthAt(m, false, tiltOff);
      });
    }
    // 현재(메인) 위치
    drawEarthAt(month, true, tiltOff);

    ctx.fillStyle = '#5a4a30';
    ctx.font = 'bold ' + titleFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'left';
    ctx.fillText('지구의 공전(위에서 내려다본 모습)', W*0.02, H*0.045);
  }

  function drawAltitudePanel(month, tiltOff){
    const panelH = ALT_BOTTOM - ALT_TOP;
    ctx.fillStyle = 'rgba(255,255,255,0.5)';
    ctx.fillRect(ALT_X0, ALT_TOP, ALT_X1-ALT_X0, panelH);
    ctx.strokeStyle = 'rgba(90,70,30,0.25)';
    ctx.lineWidth = 1;
    ctx.strokeRect(ALT_X0, ALT_TOP, ALT_X1-ALT_X0, panelH);
    ctx.fillStyle = '#5a4a30';
    ctx.font = 'bold ' + titleFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'left';
    ctx.fillText('우리나라의 남중 고도(옆에서 본 모습)', ALT_X0 + W*0.005, ALT_TOP - titleFont*0.6);

    const groundY = ALT_TOP + panelH*0.72;
    const groundX0 = ALT_X0 + W*0.02, groundX1 = ALT_X1 - W*0.02;
    ctx.fillStyle = '#f5efd9';
    ctx.fillRect(groundX0, groundY, groundX1-groundX0, panelH*0.2);
    ctx.strokeStyle = 'rgba(90,70,30,0.4)';
    ctx.lineWidth = 1.4;
    ctx.beginPath(); ctx.moveTo(groundX0, groundY); ctx.lineTo(groundX1, groundY); ctx.stroke();

    const altDeg = altitudeFor(month, tiltOff);
    const originX = (groundX0+groundX1)/2;
    const rayLen = panelH*0.62;
    const rad = deg2rad(altDeg);
    const dx = Math.cos(rad), dy = -Math.sin(rad);
    const startX = originX - dx*rayLen, startY = groundY + dy*rayLen; // dy는 음수라 위쪽으로 뻗음

    ctx.strokeStyle = '#e0790f';
    ctx.lineWidth = Math.max(2, W*0.004);
    ctx.beginPath();
    ctx.moveTo(startX, startY);
    ctx.lineTo(originX, groundY);
    ctx.stroke();

    const glow = ctx.createRadialGradient(startX,startY,1,startX,startY,W*0.055);
    glow.addColorStop(0,'rgba(255,214,120,0.9)');
    glow.addColorStop(1,'rgba(255,214,120,0)');
    ctx.fillStyle = glow;
    ctx.beginPath(); ctx.arc(startX,startY,W*0.055,0,Math.PI*2); ctx.fill();
    ctx.fillStyle = '#ffcf5c';
    ctx.beginPath(); ctx.arc(startX,startY,W*0.024,0,Math.PI*2); ctx.fill();
    ctx.strokeStyle = '#e0790f'; ctx.lineWidth = 1.6; ctx.stroke();

    // 각도 표시(지평선과 태양 광선 사이)
    const arcR = W*0.11;
    ctx.strokeStyle = '#d9432b';
    ctx.lineWidth = Math.max(1.6, W*0.003);
    ctx.beginPath();
    ctx.arc(originX, groundY, arcR, -Math.PI, -rad-Math.PI, true);
    ctx.stroke();
    ctx.fillStyle = '#d9432b';
    ctx.font = 'bold ' + labelFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText(altDeg.toFixed(1)+'°', originX - arcR*1.35, groundY - arcR*0.5);
    ctx.textAlign = 'left';

    return altDeg;
  }

  function drawScene(){
    computeLayout();
    const month = parseFloat(monthSlider.value);
    monthVal.textContent = month.toFixed(month%1===0?0:2) + '월';
    updateSliderFill(monthSlider);

    ctx.clearRect(0,0,W,H);

    const skyGrad = ctx.createLinearGradient(0,0,0,H);
    skyGrad.addColorStop(0, '#eaf3ff');
    skyGrad.addColorStop(1, '#f7f3e8');
    ctx.fillStyle = skyGrad;
    ctx.fillRect(0,0,W,H);

    drawOrbitPanel(month, noTilt.checked);
    const altDeg = drawAltitudePanel(month, noTilt.checked);

    seasonOut.textContent = seasonName(month);
    altOut.textContent = altDeg.toFixed(1) + '°';
    energyOut.textContent = energyPct(altDeg).toFixed(0) + '%';
    altBar.style.width = clamp((altDeg-20)/(90-20)*100, 4, 100) + '%';
    energyBar.style.width = clamp(energyPct(altDeg), 4, 100) + '%';
  }

  [monthSlider, noTilt, showAllPos].forEach(el=>{
    el.addEventListener('input', drawScene);
    el.addEventListener('change', drawScene);
  });

  let resizeTimer = null;
  window.addEventListener('resize', ()=>{
    clearTimeout(resizeTimer);
    resizeTimer = setTimeout(()=>{ resizeCanvas(); drawScene(); }, 80);
  });

  resizeCanvas();
  drawScene();
})();
