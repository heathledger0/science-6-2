## 1. 📖 핵심 개념 상세 정리

### 학습 목표
- 태양 고도에 따라 일정한 면적이 받는 태양 에너지양이 달라짐을 실험으로 설명할 수 있다. *(지식·이해, 과정·기능)*
- 태양 고도와 태양 에너지양의 관계를 계절별 기온 차이의 원인과 연결지어 설명할 수 있다. *(지식·이해, 과정·기능)*

### 핵심 개념 (6학년 눈높이 설명)
- 태양에서 오는 빛(에너지)은 **항상 같은 굵기의 다발**로 지구에 도달합니다. 이 빛다발이 지표면에 닿을 때, **태양 고도(각도)에 따라 퍼지는 면적이 달라집니다.**
- **태양 고도가 높을 때(예: 여름, 정오)**: 빛다발이 지표면에 거의 수직으로 닿아 **좁은 면적**에 집중됩니다. → 같은 면적이 받는 에너지양이 **많음** → 기온이 **높음**.
- **태양 고도가 낮을 때(예: 겨울, 아침·저녁)**: 빛다발이 지표면에 비스듬히(눕듯이) 닿아 **넓은 면적**에 퍼집니다. → 같은 면적이 받는 에너지양이 **적음** → 기온이 **낮음**.
- 즉, **태양 에너지의 총량은 같아도 "얼마나 좁은 곳에 집중되느냐"가 실제로 느껴지는 더위·추위를 결정**합니다. 이것이 여름이 겨울보다 더운 근본적인 이유이며, 다음 차시에서 배울 "계절이 생기는 까닭(지구 자전축 기울기 → 남중고도 변화)"과 직접 연결됩니다.

### 🗣️ 설명 스크립트 예시 (도입부 활용)
> "손전등을 벽에 똑바로(수직으로) 비출 때와, 손전등을 눕혀서 비스듬히 비출 때, 빛이 만드는 동그라미 모양이 어떻게 다를까요? 수직으로 비추면 작고 진한 동그라미가, 비스듬히 비추면 크고 흐릿한 타원이 생기죠? 태양 빛도 마찬가지예요. 오늘은 태양의 높이(고도)가 달라지면 같은 면적이 받는 '에너지의 양'이 어떻게 달라지는지 직접 실험으로 확인하고, 이게 왜 여름은 덥고 겨울은 추운지의 진짜 이유인지 알아볼 거예요."

## 2. 🧪 실험 완벽 가이드 — 태양(손전등) 고도에 따른 에너지양 비교하기

### 실험 목표
- 같은 굵기의 빛다발이 지표면에 닿는 각도(태양 고도)에 따라 퍼지는 면적이 달라짐을 관찰한다.
- 면적이 넓어질수록 같은 면적이 받는 에너지양(빛의 진하기)은 오히려 줄어든다는 것을 확인한다.

### 준비물
| 기본 준비물 | 교실 대체 가능 물품 |
|---|---|
| 손전등(밝기가 일정한 것) | 스마트폰 손전등 기능 |
| 검은색 도화지 또는 모눈종이 | 그래프 용지, 방안지 |
| 각도기 | 삼각자로 어림 측정 |
| 손전등 고정 스탠드(또는 책 받침대) | 클립보드, 나무 블록으로 각도 고정 |
| 색연필, 자 | - |
| (심화, 선택) 태양전지판 + 소형 전동기(프로펠러) 또는 LED | 학교 과학실 태양광 실험 키트 |

### 실험 단계
1. 검은 도화지(또는 모눈종이)를 바닥이나 책상에 평평하게 놓습니다.
2. 손전등을 도화지와 **수직(90°)**이 되도록 위에서 비추고, 빛이 만든 동그라미(빛무늬) 테두리를 색연필로 따라 그립니다. 그 안에 들어간 모눈 칸 수를 세어 기록합니다.
3. 손전등의 높이(도화지에서 손전등까지 거리)는 그대로 둔 채, 이번에는 각도기로 **45°**를 맞춰 손전등을 기울여 비춥니다. 빛무늬를 다시 따라 그리고 칸 수를 셉니다.
4. 손전등을 더 낮은 각도(약 **20~30°**)로 눕혀 반복합니다.
5. 세 각도에서 그린 빛무늬 세 개를 나란히 놓고 비교합니다 — 각도가 낮아질수록 빛무늬가 길쭉하고 넓게 퍼지는 것을 확인합니다.
6. **토의**: "손전등에서 나오는 빛의 양(밝기)은 세 번 다 똑같았는데, 왜 무늬의 진하기(밝기)는 다르게 느껴졌을까요?" → 같은 양의 빛이 더 넓은 면적에 퍼지면 한 칸이 받는 빛은 더 적어진다는 결론을 이끌어냅니다.
7. **(심화, 선택)** 태양전지판에 전동기(또는 LED)를 연결하고, 손전등을 각도별로 비추며 전동기의 회전 속도(또는 LED 밝기)가 어떻게 달라지는지 비교해, 같은 결론을 다른 방식으로도 확인합니다.

> 모둠별로 세 각도를 나눠 맡아 동시에 실험한 뒤 칠판에 결과를 모으면 시간을 절약하면서도 더 많은 각도 데이터를 비교할 수 있습니다.

### ⚠️ 안전 유의사항
- **손전등 빛을 서로의 눈에 직접 비추지 않도록** 사전에 반드시 지도합니다.
- 태양전지·전동기 실험 시 **전선 연결부와 회전하는 프로펠러 날에 손가락이 닿지 않도록** 주의합니다.
- 실제 태양광으로 실험을 확장할 경우(예: 운동장에서 그림자·빛무늬 관찰), **태양을 직접 쳐다보지 않도록** 지도합니다.
- 각도기·자 등 뾰족한 학용품을 던지거나 장난치지 않도록 지도합니다.

## 3. 🛡️ 오개념 철벽 방어

### 오개념 1 — "지구가 태양에 가까워져서 여름이 되고, 멀어져서 겨울이 된다" *(가장 흔하고 뿌리 깊은 오개념)*
- **왜 틀렸나**: 지구와 태양 사이의 거리 변화는 계절과 거의 무관합니다. 실제로 지구는 (북반구 기준) 겨울인 1월경에 태양에 오히려 더 가깝고, 여름인 7월경에 더 멉니다. 계절을 만드는 진짜 원인은 거리가 아니라 **태양 고도(에너지가 집중되는 정도)**입니다.
- **교정 발문**: "만약 거리 때문에 계절이 바뀐다면, 북반구와 남반구가 같은 시기에 같은 계절이어야 하지 않을까요? 그런데 우리나라가 여름일 때 호주는 겨울입니다. 왜 그럴까요?" → 같은 지구, 같은 태양-지구 거리인데 계절이 반대라는 사실이 거리 오개념을 강하게 흔듭니다.

### 오개념 2 — "태양 고도가 높으면 태양이 더 크게 보여서 에너지가 많다고 생각함"
- **왜 틀렸나**: 태양의 크기(보이는 크기)는 고도와 관계없이 거의 일정합니다. 에너지양이 달라지는 진짜 이유는 태양의 크기가 아니라, **같은 굵기의 빛다발이 지표면에 닿는 각도에 따라 "퍼지는 면적"이 달라지기 때문**입니다.
- **교정 발문**: "이 시뮬레이터에서 태양 아이콘의 크기는 항상 똑같죠? 그런데도 빛이 닿는 면적은 왜 달라질까요?" → 시뮬레이터의 빛다발 폭이 항상 고정되어 있다는 점을 짚어주면 효과적입니다.

### 오개념 3 — "낮의 길이만 길어지면 무조건 더 더워진다고 생각함(낮의 길이=기온이라고 단순화)"
- **왜 문제인가**: 낮의 길이(일조 시간)도 기온에 영향을 주지만, **태양 고도(에너지 집중도)가 기온에 더 직접적인 영향**을 줍니다. 두 요인을 구분하지 못하면 "왜 5~6월보다 7~8월이 더 더운지"(낮의 길이는 하지 근처가 가장 긴데도) 같은 질문에서 혼란이 생깁니다.
- **교정 발문**: "낮의 길이가 가장 긴 날(하지, 6월 21일경)과 실제로 가장 더운 날(7~8월) 중 어느 게 더 늦게 올까요? 왜 시간 차이가 생길까요?" (심화 질문 — 바다·땅이 데워지는 데 시간이 걸리는 '계절 지연' 개념까지 확장 가능)

## 4. 💡 호기심 천국 & 심화 탐구 (영재 교육 연계)

- **위도와 태양 에너지 — 왜 적도는 늘 덥고 극지방은 늘 추울까?**: 적도 지방은 일 년 내내 태양이 머리 위 가까이(높은 고도)에서 비추고, 극지방은 일 년 내내 태양이 비스듬히(낮은 고도)에서 비춥니다. 오늘 배운 원리를 위도 차이에 그대로 적용하면 지구의 기후대(열대·온대·한대)가 왜 그렇게 나뉘는지 설명할 수 있습니다.
- **태양광 발전과의 연결(공학 심화)**: 태양광 발전소는 패널이 태양 빛을 최대한 수직에 가깝게 받도록 계절과 위도에 맞춰 **패널의 경사각**을 설계합니다(1차시에서 소개한 '태양광 추적 장치'와 직접 연결). "우리나라에서 태양광 패널을 설치한다면 여름과 겨울 중 언제 각도를 더 눕혀야(또는 세워야) 할까요?"
- **온실 효과와 지구 온난화**: 지표면에 도달한 태양 에너지의 일부는 대기 중 온실가스에 의해 갇힙니다. 태양 고도에 따른 에너지 집중도 개념은 "왜 온실가스가 늘면 지구 평균 기온이 올라가는가"를 이해하는 다음 단계로 자연스럽게 이어집니다.
- **역사 속 지혜 — 남향집과 처마의 과학**: 우리나라 전통 한옥은 처마의 길이를 계산해, **태양 고도가 높은 여름에는 햇빛을 막아 시원하게, 태양 고도가 낮은 겨울에는 햇빛이 깊숙이 들어오게** 설계했습니다. "처마 길이를 어떻게 계산했을지" 상상해 보는 활동으로 확장할 수 있습니다.
- **생각해 볼 질문(영재 학급용)**: "달에도 계절이 있을까요? 달의 자전축 기울기는 지구보다 훨씬 작습니다(약 1.5°). 오늘 배운 원리로 볼 때, 달의 계절 변화는 지구보다 클까요, 작을까요?"

## 5. 💻 인터랙티브 시뮬레이터 (Gemini Canvas용 완전한 코드)

**기획 의도**: 실제 손전등 실험은 빛무늬를 손으로 그리고 칸을 세는 데 시간이 걸리고, 여러 각도를 동시에 비교하기 어렵습니다. 이 시뮬레이터는 **태양 고도 슬라이더**로 각도를 자유롭게 조절하며 빛다발이 지면에 닿는 폭(모눈 칸수)과 빛의 진하기(%)를 실시간으로 계산해 보여주고, **"세 가지 고도 한번에 비교하기"**로 오개념을 한 화면에서 바로 교정할 수 있도록 설계했습니다. QR코드로 학생 개인 기기에서도 실행 가능합니다.

**설계 근거(해외 사례 분석 반영)**: NAAP(Nebraska Astronomy Applet Project)의 「Seasons and Ecliptic Simulator」, 미국 지구과학 교실에서 널리 쓰이는 "Angle of Insolation" 손전등 실습 등 관련 시뮬레이터·실습 자료를 분석해 다음을 반영했습니다.
- **빛무늬(하늘에서 내려다본 모습) 패널**: 옆에서 본 광선 다발 도식만으로는 "실제 손전등 실험에서 종이에 따라 그리는 모양"과 바로 연결되지 않는다는 점을 보완해, 90°일 때는 원, 고도가 낮아질수록 세로로 길쭉해지는 타원을 실제 실험처럼 보여주고, 점선으로 90° 기준 크기를 겹쳐 그려 즉시 비교할 수 있게 했습니다.
- **하늘을 직접 드래그하는 조작**: NAAP 시뮬레이터가 태양/관측자를 직접 끌어서 조작하게 한 것을 참고해, 슬라이더뿐 아니라 화면의 하늘 영역을 직접 끌어도 태양 고도가 바뀌도록 만들어 더 직관적으로 조작할 수 있게 했습니다.
- **초등 6학년 눈높이에 맞춘 단순화**: 처음 버전에는 "태양 고도–에너지 그래프(사인 곡선)"도 있었지만, 삼각함수를 배우지 않은 6학년에게는 오히려 어려운 표현이라 판단해 제거했습니다. 대신 두 개의 시각 자료(옆에서 본 광선 다발 + 위에서 본 빛무늬)와 쉬운 말(예: "빛의 진하기", "몇 배 넓게 퍼졌나")만으로 핵심 개념이 전달되도록 다듬었습니다.

```html
(function(){

  //  화면 폭에 비례해 항상 큼직하게 보이도록 모든 수치를 W·H의 비율로 정의합니다.)
  let W = 900, H = 1125;

  function resizeCanvas(){
    const rect = canvas.getBoundingClientRect();
    const dpr = window.devicePixelRatio || 1;
    W = rect.width;
    H = rect.height;
    canvas.width = Math.max(1, Math.round(W * dpr));
    canvas.height = Math.max(1, Math.round(H * dpr));
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);

  // ---- 레이아웃 상수(모두 W·H에 대한 비율) ----
  let GROUND_Y, SCENE_BOTTOM, PANEL_TOP, PANEL_BOTTOM, FOOT_X0, FOOT_X1;
  let GRID, BEAM, sunGlowR, sunCoreR, mainFont, subFont, panelTitleFont, captionFont;
  const ALT_MIN = 15, ALT_MAX = 90;

  function computeLayout(){

    SCENE_BOTTOM = H * 0.52;
    PANEL_TOP = H * 0.60;
    PANEL_BOTTOM = H * 0.97;
    FOOT_X0 = W * 0.022; FOOT_X1 = W - W*0.022;

    GRID = W * 0.02;      // 모눈 한 칸의 크기. 실제 실험의 "모눈종이 칸 세기"와 대응됩니다.
    BEAM = W * 0.038;     // 태양 광선 다발의 두께. 모든 각도에서 항상 동일하게 유지됩니다.
    sunGlowR = W * 0.085;
    sunCoreR = W * 0.036;
    mainFont = W * 0.05;
    subFont = W * 0.04;
    panelTitleFont = W * 0.042;
    captionFont = W * 0.042;
  }

  const altSlider = document.getElementById('altSlider');
  const altVal = document.getElementById('altVal');
  const compareMode = document.getElementById('compareMode');
  const heatOverlay = document.getElementById('heatOverlay');
  const widthOut = document.getElementById('widthOut');
  const densityOut = document.getElementById('densityOut');
  const ratioOut = document.getElementById('ratioOut');
  const widthBar = document.getElementById('widthBar');
  const densityBar = document.getElementById('densityBar');
  const ratioBar = document.getElementById('ratioBar');

  function deg2rad(d){ return d * Math.PI / 180; }
  function clamp(v,a,b){ return Math.max(a, Math.min(b, v)); }
  function energyPct(altDeg){ return Math.sin(deg2rad(altDeg)) * 100; }
  const MAX_RATIO = 1/Math.sin(deg2rad(ALT_MIN)); // 가장 낮은 고도(15°)일 때의 배율 = 막대그래프 기준 최댓값
  // 고도(도) -> 지면에 닿는 빛의 폭(px). 광선 다발 두께(BEAM)가 항상 같으므로,
  // 고도가 낮을수록(각도가 누울수록) 같은 빛다발이 훨씬 넓은 폭으로 퍼져서 닿습니다.
  function groundWidthPx(altDeg){ return BEAM / Math.sin(deg2rad(altDeg)); }

  function updateSliderFill(slider){
    const min = parseFloat(slider.min), max = parseFloat(slider.max), v = parseFloat(slider.value);
    const pct = ((v - min) / (max - min)) * 100;
    slider.style.setProperty('--fill', pct + '%');
  }

  // 약함(연한 노랑) -> 강함(진한 빨강)으로, 눈에 확 띄게 색이 크게 바뀌도록 함
  function heatColor(densityPct, baseAlpha){
    const t = clamp(densityPct/100, 0, 1);
    const r = Math.round(255 + (176-255)*t);
    const g = Math.round(224 + (20-224)*t);
    const b = Math.round(140 + (24-140)*t);
    return `rgba(${r},${g},${b},${baseAlpha})`;
  }

  // ---- 위쪽: 광선 다발이 지면에 닿는 옆모습(단면) 장면 ----
  function drawZone(zoneLeft, zoneWidth, altDeg, isMain){
    const zoneCenterX = zoneLeft + zoneWidth/2;
    const widthPx = groundWidthPx(altDeg);
    const halfW = widthPx/2;
    const patchLeft = zoneCenterX - halfW;

    ctx.lineCap = 'round';
    for(let i=0;i<rayCount;i++){
      const t = rayCount===1 ? 0.5 : i/(rayCount-1);
      const hitX = patchLeft + widthPx*t;
      const startX = hitX - dx*segLen;
      const startY = GROUND_Y - dy*segLen;
      ctx.beginPath();
      ctx.moveTo(startX, startY);
      ctx.lineTo(hitX, GROUND_Y);
      ctx.stroke();
    }

    // 태양(광원) 아이콘: 광선 다발 맨 위쪽 중앙에 배치
    const sunHitX = patchLeft + widthPx*0.5;
    const sunX = sunHitX - dx*segLen;
    const sunY = GROUND_Y - dy*segLen;
    const sunGlow = ctx.createRadialGradient(sunX,sunY,1,sunX,sunY,sunGlowR);
    sunGlow.addColorStop(0,'rgba(255,214,120,0.9)');
    sunGlow.addColorStop(1,'rgba(255,214,120,0)');
    ctx.fillStyle = sunGlow;
    ctx.beginPath(); ctx.arc(sunX,sunY,sunGlowR,0,Math.PI*2); ctx.fill();
    ctx.fillStyle = '#ffcf5c';
    ctx.beginPath(); ctx.arc(sunX,sunY,sunCoreR,0,Math.PI*2); ctx.fill();
    ctx.strokeStyle = '#e0790f';
    ctx.lineWidth = Math.max(1.5, W*0.0022);
    ctx.stroke();

    ctx.restore();

    // 빛이 닿는 면적(에너지 밀도에 따라 연한 노랑 -> 진한 빨강으로 색이 뚜렷하게 바뀜)
    const stripH = Math.max(6, H*0.014);
    ctx.fillStyle = heatOverlay.checked ? heatColor(densityPct, 0.55 + clamp(densityPct/100,0,1)*0.4) : 'rgba(217,67,43,0.35)';
    ctx.beginPath();
    ctx.rect(patchLeft, GROUND_Y-stripH/2, widthPx, stripH);
    ctx.fill();
    ctx.strokeStyle = 'rgba(90,60,20,0.35)';
    ctx.lineWidth = 1;
    ctx.strokeRect(patchLeft, GROUND_Y-stripH/2, widthPx, stripH);

    // 각도·에너지 라벨
    ctx.fillStyle = isMain ? '#c8720f' : '#8a7a5c';
    ctx.font = (isMain ? 'bold ' : '') + mainFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText('고도 ' + altDeg.toFixed(0) + '°', zoneCenterX, GROUND_Y + mainFont*2.0);
    ctx.fillText('에너지 ' + densityPct.toFixed(0) + '%', zoneCenterX, GROUND_Y + mainFont*3.3);
    ctx.textAlign = 'left';

    if(isMain) lastMainSun = { x:sunX, y:sunY, zoneCenterX };
    return { widthPx, densityPct };
  }

  // 광선 다발 두께(BEAM)가 지름인 원이 90°일 때의 모양이고, 고도가 낮아질수록
  // 세로 방향으로만 길쭉한 타원(둘레는 넓지만 짧은 변은 그대로)으로 늘어납니다.
  function drawFootprintPanel(zones){
    const panelW = FOOT_X1 - FOOT_X0, panelH = PANEL_BOTTOM - PANEL_TOP;
    ctx.fillStyle = 'rgba(255,255,255,0.5)';
    ctx.fillRect(FOOT_X0, PANEL_TOP, panelW, panelH);
    ctx.strokeStyle = 'rgba(90,70,30,0.25)';
    ctx.lineWidth = 1;
    ctx.strokeRect(FOOT_X0, PANEL_TOP, panelW, panelH);
    ctx.fillStyle = '#5a4a30';
    ctx.font = 'bold ' + panelTitleFont.toFixed(1) + 'px sans-serif';
    ctx.textAlign = 'left';
    ctx.fillText('빛무늬(하늘에서 내려다본 모습)', FOOT_X0 + W*0.005, PANEL_TOP - panelTitleFont*0.6);

    const slotW = panelW/zones.length;
    const cy = PANEL_TOP + panelH*0.5;
    const maxRy = panelH*0.4;
    const cellPx = GRID * 0.56;

    zones.forEach((z, i)=>{
      const cx = FOOT_X0 + slotW*(i+0.5);
      const rx = BEAM/2;
      const ry = clamp((BEAM/2)/Math.sin(deg2rad(z.alt)), rx, maxRy);
      const densityPct = energyPct(z.alt);

      ctx.save();
      ctx.beginPath();
      ctx.rect(FOOT_X0+slotW*i+2, PANEL_TOP+2, slotW-4, panelH-4);
      ctx.clip();

      // 모눈
      ctx.strokeStyle = 'rgba(90,70,30,0.12)';
      ctx.lineWidth = 1;
      for(let gx=cx-6*cellPx; gx<=cx+6*cellPx; gx+=cellPx){
        ctx.beginPath(); ctx.moveTo(gx, PANEL_TOP); ctx.lineTo(gx, PANEL_BOTTOM); ctx.stroke();
      }
      for(let gy=cy-6*cellPx; gy<=cy+6*cellPx; gy+=cellPx){
        ctx.beginPath(); ctx.moveTo(FOOT_X0+slotW*i, gy); ctx.lineTo(FOOT_X0+slotW*(i+1), gy); ctx.stroke();
      }

      // 90°일 때(기준) 크기 — 항상 원, 점선으로 겹쳐 그려 비교 기준으로 삼음
      ctx.strokeStyle = 'rgba(50,40,20,0.45)';
      ctx.setLineDash([3,3]);
      ctx.lineWidth = 1.3;
      ctx.beginPath();
      ctx.ellipse(cx, cy, rx, rx, 0, 0, Math.PI*2);
      ctx.stroke();
      ctx.setLineDash([]);

      // 실제 빛무늬(현재 고도) — 연한 노랑(약함) ~ 진한 빨강(강함)으로 뚜렷하게 구분
      ctx.fillStyle = heatOverlay.checked ? heatColor(densityPct, 0.6 + clamp(densityPct/100,0,1)*0.35) : 'rgba(217,67,43,0.4)';
      ctx.strokeStyle = z.main ? '#c8720f' : '#8a7a5c';
      ctx.lineWidth = z.main ? W*0.0028 : W*0.0018;
      ctx.beginPath();
      ctx.ellipse(cx, cy, rx, ry, 0, 0, Math.PI*2);
      ctx.fill();
      ctx.stroke();

      ctx.restore();

      const cellsCovered = (Math.PI*rx*ry)/(cellPx*cellPx);
      ctx.fillStyle = z.main ? '#c8720f' : '#8a7a5c';
      ctx.font = (z.main?'bold ':'') + captionFont.toFixed(1) + 'px sans-serif';
      ctx.textAlign = 'center';
      ctx.fillText(z.alt.toFixed(0)+'° · 약 '+cellsCovered.toFixed(0)+'칸', cx, PANEL_BOTTOM - captionFont*0.7);
      ctx.textAlign = 'left';
    });
  }

  let lastMainSun = null;

  function drawScene(){
    computeLayout();
    const altDeg = parseFloat(altSlider.value);
    altVal.textContent = altDeg + '°';
    updateSliderFill(altSlider);

    ctx.clearRect(0,0,W,H);

    // 하늘
    const skyGrad = ctx.createLinearGradient(0,0,0,GROUND_Y);
    skyGrad.addColorStop(0, '#bfe3ff');
    skyGrad.addColorStop(1, '#eaf7ff');
    ctx.fillStyle = skyGrad;
    ctx.fillRect(0,0,W,GROUND_Y);

    // 땅(모눈종이) — 광선 다발 장면 구간만
    ctx.fillStyle = '#f5efd9';
    ctx.fillRect(0,GROUND_Y,W,SCENE_BOTTOM-GROUND_Y);
    ctx.strokeStyle = 'rgba(90,70,30,0.16)';
    ctx.lineWidth = 1;
    for(let x=0; x<=W; x+=GRID){
      ctx.beginPath(); ctx.moveTo(x,GROUND_Y); ctx.lineTo(x,SCENE_BOTTOM); ctx.stroke();
    }
    for(let y=GROUND_Y; y<=SCENE_BOTTOM; y+=GRID){
      ctx.beginPath(); ctx.moveTo(0,y); ctx.lineTo(W,y); ctx.stroke();
    }
    ctx.strokeStyle = 'rgba(90,70,30,0.4)';
    ctx.lineWidth = 1.6;
    ctx.beginPath(); ctx.moveTo(0,GROUND_Y); ctx.lineTo(W,GROUND_Y); ctx.stroke();

    const zones = compareMode.checked
      ? [
          { alt: clamp(altDeg-28, ALT_MIN, ALT_MAX), main:false },
          { alt: altDeg, main:true },
          { alt: clamp(altDeg+28, ALT_MIN, ALT_MAX), main:false }
        ]
      : [ { alt: altDeg, main:true } ];

    const zoneWidth = W/zones.length;
    let mainResult = null;
    zones.forEach((z, i)=>{
      const res = drawZone(zoneWidth*i, zoneWidth, z.alt, z.main);
      if(z.main) mainResult = res;
      if(compareMode.checked && i>0){
        ctx.strokeStyle = 'rgba(120,110,90,0.3)';
        ctx.setLineDash([4,4]);
        ctx.beginPath();
        ctx.moveTo(zoneWidth*i, 0); ctx.lineTo(zoneWidth*i, SCENE_BOTTOM);
        ctx.stroke();
        ctx.setLineDash([]);
      }
    });

    drawFootprintPanel(zones);

    const widthCells = mainResult.widthPx / GRID;
    const ref90Cells = BEAM / GRID; // 90°일 때(최소 폭)의 칸수 = 기준
    const ratio = widthCells/ref90Cells;
    const maxWidthCells = (BEAM/GRID) * MAX_RATIO;

    widthOut.textContent = widthCells.toFixed(1) + '칸';
    densityOut.textContent = mainResult.densityPct.toFixed(0) + '%';
    ratioOut.textContent = ratio.toFixed(1) + '배';

    widthBar.style.width = clamp(widthCells/maxWidthCells*100, 6, 100) + '%';
    densityBar.style.width = clamp(mainResult.densityPct, 6, 100) + '%';
    ratioBar.style.width = clamp((ratio-1)/(MAX_RATIO-1)*100, 6, 100) + '%';
  }

  [altSlider, compareMode, heatOverlay].forEach(el=>{
    el.addEventListener('input', drawScene);
    el.addEventListener('change', drawScene);
  });

  // ---- 하늘(광선 다발 장면 위쪽)을 직접 드래그해서 태양 고도를 조절 ----
  let dragging = false;
  function pointerToCanvas(e){
    const rect = canvas.getBoundingClientRect();
    return { x: e.clientX - rect.left, y: e.clientY - rect.top };
  }
  function altFromPointer(pt){
    if(!lastMainSun) return parseFloat(altSlider.value);
    // 좌우 어느 쪽에서 끌어도 자연스럽게 동작하도록 수평 거리는 항상 양수로 취급(대칭)
    const dx = Math.abs(lastMainSun.zoneCenterX - pt.x);
    const dy = GROUND_Y - pt.y;
    const a = Math.atan2(dy, dx) * 180/Math.PI;
    return clamp(Math.round(a), ALT_MIN, ALT_MAX);
  }
  canvas.addEventListener('pointerdown', (e)=>{
    const pt = pointerToCanvas(e);
    if(pt.y < GROUND_Y){
      dragging = true;
      canvas.setPointerCapture(e.pointerId);
      altSlider.value = altFromPointer(pt);
      drawScene();
    }
  });
  canvas.addEventListener('pointermove', (e)=>{
    if(!dragging) return;
    altSlider.value = altFromPointer(pointerToCanvas(e));
    drawScene();
  });
  ['pointerup','pointercancel','pointerleave'].forEach(evt=>{
    canvas.addEventListener(evt, ()=>{ dragging = false; });
  });

  // 화면 크기가 바뀔 때(회전, 창 크기 조절 등)마다 다시 맞춰 그림
  let resizeTimer = null;
  window.addEventListener('resize', ()=>{
    clearTimeout(resizeTimer);
    resizeTimer = setTimeout(()=>{ resizeCanvas(); drawScene(); }, 80);
  });

  resizeCanvas();
  drawScene();
})();
</script>
</body>
</html>

```

**사용법**: 위 코드를 Gemini Canvas(또는 캔버스 지원 환경)에 붙여넣으면 즉시 실행됩니다. 태양 고도를 90°(수직)에서 점점 낮추면 빛다발이 퍼지는 폭이 넓어지고 에너지 밀도(%)가 줄어드는 것을 실시간으로 보여줄 수 있고, "3단계 동시 비교 모드"로 오개념 1·2번을 한 화면에서 교정할 수 있습니다. (테스트 완료: 브라우저에서 정상 작동 확인)
