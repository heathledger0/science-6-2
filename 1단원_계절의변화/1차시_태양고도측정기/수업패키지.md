## 1. 📖 핵심 개념 상세 정리

### 학습 목표 (지도서 명시)
- 태양 고도를 알아보고, 태양 고도 측정기를 설계할 수 있다. *(지식·이해, 과정·기능)*
- 설계한 태양 고도 측정기에 따라 태양 고도 측정기를 만들 수 있다. *(과정·기능, 가치·태도)*

### 핵심 개념 (6학년 눈높이 설명)
- **태양 고도**란 태양의 높이를 나타내는 값으로, **태양이 지표면과 이루는 각**을 말합니다.
- 태양은 하루 동안 동쪽 하늘 → 남쪽 하늘 → 서쪽 하늘로 위치가 바뀌면서 높이(고도)도 함께 달라집니다. (실제로는 지구가 자전하기 때문에 태양이 움직이는 것처럼 보이는 것입니다.)
- 태양 고도를 측정하는 도구를 직접 설계해 보면서, 그림자와 실이 이루는 각을 이용해 태양의 높이를 잴 수 있다는 원리를 이해합니다.
- 태양 고도 측정기는 만드는 방식에 따라 여러 종류가 있습니다.
  - ① 막대기(수수깡)와 실을 이용하는 방식 — 막대 그림자 끝과 실이 이루는 각을 측정
  - ② 각도기를 기울여 사용하는 방식 — 빨대 사이로 태양 빛이 통과할 때의 각을 측정
  - ③ 접이식 종이 각도기를 이용하는 방식 — 종이 사이로 빛이 보일 때의 각을 측정

### 🗣️ 설명 스크립트 예시 (도입부 활용)
> "여러분, 아침에 등교할 때와 점심시간, 그리고 하교할 때 그림자 길이가 다르다는 걸 느껴본 적 있나요? 그림자가 길어졌다 짧아졌다 하는 건 바로 태양의 '높이'가 계속 바뀌기 때문이에요. 오늘은 이 태양의 높이, 즉 **태양 고도**를 직접 잴 수 있는 나만의 측정기를 설계하고 만들어 볼 거예요. 여러분이 만든 측정기로 앞으로 몇 주 동안 우리 학교 운동장의 태양 고도를 계속 측정하게 될 거랍니다!"

## 2. 🧪 실험(제작) 완벽 가이드 — 태양 고도 측정기 만들기

### 실험 목표
- 그림자와 실(또는 각도기)을 이용해 태양 고도를 측정하는 원리를 이해하고, 이를 적용한 태양 고도 측정기를 스스로 설계하여 만든다.
- (핵심 원리) **막대기의 길이가 달라져도 측정되는 태양 고도 값은 변하지 않는다**는 것을 실제로 확인한다.

### 준비물
| 기본 준비물(지도서) | 교실 대체 가능 물품 |
|---|---|
| 우드록(폼보드) | 두꺼운 도화지, 하드보드지 |
| 수수깡 | 나무젓가락, 빨대, 이쑤시개 |
| 시침바늘(장구핀) | 압정, 클립을 편 것 |
| 실 | 재봉실, 낚싯줄 |
| 구멍 뚫린 각도기 / 일반 각도기 | 학용품 각도기 + 송곳(교사 사전 천공) |
| 가위, 양면테이프, 자 | - |

### 실험(제작) 단계
**[방식 A] 막대기+실 이용 태양 고도 측정기**
1. 우드록을 정사각형(또는 직사각형) 모양으로 자르고, 양면테이프로 자를 붙입니다.
2. 수수깡을 10cm 정도로 자르고, 자의 '0' 위치에 수직이 되도록 꽂습니다.
3. 수수깡 끝부분에 실을 묶습니다.
4. 실의 다른 한쪽 끝을 각도기 가운데에 있는 구멍에 끼웁니다.
5. 햇빛이 잘 드는 평평한 곳에 측정기를 놓고, 수수깡의 그림자 끝에 실을 맞춘 뒤 실과 그림자(자)가 이루는 각을 각도기로 읽습니다.

**[방식 B] 각도기를 기울여 사용하는 태양 고도 측정기**
1. 우드록을 정사각형으로 자르고, 우드록의 중간 높이에 선을 긋습니다.
2. 빨대를 5cm 정도로 잘라 각도기의 '0' 선에 맞춰 붙입니다.
3. 빨대와 일직선이 되는 위치에 작은 종이판을 붙입니다.
4. 우드록에 각도기를 고정하기 위해 장구핀을 구멍 뚫린 각도기의 중심에 넣습니다.
5. 태양 빛이 빨대 사이로 통과해 종이판에 빛이 보일 때, 각도기와 우드록이 이루는 각을 읽습니다.

**[방식 C] 접이식 종이 각도기 이용**
1. 두꺼운 종이에 양면테이프로 우드록을 붙입니다.
2. 다른 두꺼운 종이를 접어 각이 조절되도록 만듭니다.
3. 각이 조절되는 두꺼운 종이에 이쑤시개를 끼웁니다.
4. 투명 필름의 각도기를 붙여 종이 사이로 태양 빛이 통과해 보이는 각을 읽습니다.

> 모둠별로 세 가지 방식 중 하나를 선택(또는 자유 설계)하게 하고, 완성 후 서로 다른 방식의 측정기를 비교·소개하는 시간을 가지면 좋습니다. (지도서 "전개2: 다양한 태양 고도 측정기")

### ⚠️ 안전 유의사항
- **가위·시침바늘(장구핀) 사용**: 뾰족한 부분에 찔리지 않도록 사용 전 반드시 안전 수칙을 안내하고, 사용 후 바로 정리함에 보관합니다.
- **장구핀을 우드록 뒷면으로 살짝만 튀어나오게** 꽂아, 뒷면의 뾰족한 부분에 다른 학생이 다치지 않도록 지도합니다.
- **태양 직시 금지**: 그림자를 이용해 측정하므로 태양을 직접 볼 필요는 없지만, 호기심에 태양을 직접 쳐다보는 학생이 없도록 사전에 반드시 지도합니다(눈 손상 위험).
- 야외 측정 활동 시 실외 이동 안전(계단, 문턱 등) 및 여름철 폭염 대비(모자, 물)를 함께 안내합니다.
- 준비물(가위, 실, 시침바늘)을 던지거나 장난치지 않도록 지도합니다.

## 3. 🛡️ 오개념 철벽 방어

### 오개념 1 — "막대기(수수깡) 길이가 달라지면 측정되는 태양 고도도 달라진다" *(지도서에 실제로 제시된 오개념)*
- **왜 틀렸나**: 태양 빛은 매우 멀리서 오기 때문에 지표면에 거의 평행하게 들어옵니다. 막대기가 길어지면 그림자도 함께 길어지고, 막대기가 짧아지면 그림자도 함께 짧아져서 **막대기 길이와 그림자 길이의 비율(=각도)은 항상 일정**합니다.
- **교정 발문**: "막대기 길이를 2배로 늘리면 그림자 길이는 어떻게 될까요? 그럼 그때 실이 가리키는 각도는 커질까요, 작아질까요, 그대로일까요?" → 모둠별로 길이가 다른 막대 3개로 직접 측정해 비교하게 하면 인지 갈등이 확실히 해소됩니다. (아래 5번 시뮬레이터의 "막대기 3개 비교 모드"를 활용하면 즉시 시각적으로 확인시킬 수 있습니다.)

### 오개념 2 — "태양이 움직여서 그림자가 달라진다고만 생각하고, 지구가 자전한다는 사실과 연결하지 못함"
- **왜 문제인가**: 하루 동안 그림자와 태양 고도가 달라지는 현상을 관찰은 하지만, 이를 지구의 자전과 연결 짓지 못하면 이후 "계절 변화의 원인"(자전축 기울기) 차시 학습에서 개념이 단절됩니다.
- **교정 발문**: "우리는 태양이 움직인다고 느끼지만, 실제로 움직이는 것은 무엇일까요? 회전목마를 타고 있을 때 주변 풍경이 움직이는 것처럼 보이는 경험과 비교해 볼까요?"

### 오개념 3 — "태양 고도 측정기는 아무 방향, 아무 각도로 놓아도 똑같이 측정된다"
- **왜 틀렸나**: 수수깡(막대)이 바닥에 수직으로 세워져 있지 않거나 측정기가 기울어져 있으면 그림자 길이가 왜곡되어 잘못된 각도가 측정됩니다.
- **교정 발문**: "측정기를 살짝 기울여서 재보면 아까와 같은 각도가 나올까요? 왜 수수깡을 자에 '수직으로' 꽂아야 한다고 했을까요?" → 직접 측정기를 기울여 오차를 눈으로 확인하게 하면 효과적입니다.

## 4. 💡 호기심 천국 & 심화 탐구 (영재 교육 연계)

- **삼각비와의 연결(수학 심화)**: 그림자 길이 = 막대 길이 ÷ tan(태양 고도)라는 관계식이 성립합니다. 아직 삼각함수를 배우지 않았지만, "막대 길이와 그림자 길이의 비율이 태양 고도에 따라 일정한 값을 가진다"는 것을 눈치채는 학생에게는 중학교 수학(삼각비)과 연결되는 개념임을 짚어줄 수 있습니다.
- **역사 속 태양 고도 측정 — 해시계(앙부일구)**: 조선시대 세종대왕 때 만든 앙부일구는 오늘날 우리가 만드는 태양 고도 측정기와 원리가 같습니다(그림자로 시간과 계절을 읽음). "옛 과학자들은 어떻게 시계 없이 시간을 알았을까?"라는 질문으로 확장할 수 있습니다.
- **최신 공학 기술 — 태양광 추적 시스템(Solar Tracker)**: 실제 태양광 발전소에서는 태양 고도와 방위각을 실시간으로 계산해 태양광 패널의 각도를 자동으로 조절하는 '태양광 추적 장치'를 사용합니다. 이렇게 하면 고정형 패널보다 발전 효율이 20~40% 더 높아집니다. 오늘 만든 측정기의 원리가 실제 신재생에너지 산업에도 쓰인다는 점을 소개해 보세요.
- **실생활 응용 — 건축과 일조권 설계**: 건축 설계사들은 태양 고도를 계산해 건물의 그늘이 옆 건물이나 도로에 얼마나 지는지, 겨울에도 집 안에 햇빛이 충분히 들어오는지를 미리 예측합니다. 아파트 동 간 거리를 정할 때도 태양 고도 계산이 활용됩니다.
- **생각해 볼 질문(영재 학급용)**: "적도 지방과 우리나라는 태양 고도가 똑같이 변할까요? 위도가 다르면 태양 고도는 어떻게 달라질지 예상해 봅시다." (다음 차시 '계절별 태양의 남중 고도' 학습의 좋은 예고편이 됩니다.)

```html
<script>
(function(){
  const canvas = document.getElementById('stage');
  const ctx = canvas.getContext('2d');
  const W = canvas.width, H = canvas.height;
  const groundY = H * 0.72;
  const pxPerCm = 6; // 화면상 1cm를 몇 픽셀로 그릴지 (표현용 스케일)

  const elevSlider = document.getElementById('elevSlider');
  const stickSlider = document.getElementById('stickSlider');
  const elevVal = document.getElementById('elevVal');
  const stickVal = document.getElementById('stickVal');
  const compareMode = document.getElementById('compareMode');
  const showRays = document.getElementById('showRays');
  const showArc = document.getElementById('showArc');
  const shadowOut = document.getElementById('shadowOut');
  const measuredOut = document.getElementById('measuredOut');
  const diffOut = document.getElementById('diffOut');

  function deg2rad(d){ return d * Math.PI / 180; }
  function rad2deg(r){ return r * 180 / Math.PI; }

  function updateSliderFill(slider){
    const min = parseFloat(slider.min), max = parseFloat(slider.max), v = parseFloat(slider.value);
    const pct = ((v - min) / (max - min)) * 100;
    slider.style.setProperty('--fill', pct + '%');
  }

  function drawScene(){
    const elevDeg = parseFloat(elevSlider.value);
    const stickCm = parseFloat(stickSlider.value);
    elevVal.textContent = elevDeg + '°';
    stickVal.textContent = stickCm + 'cm';
    updateSliderFill(elevSlider);
    updateSliderFill(stickSlider);

    ctx.clearRect(0,0,W,H);

    // 하늘은 canvas 자체 CSS 배경(고정 주간 하늘)을 사용하고, 여기서는 태양/땅/막대기만 그림
    // 땅
    ctx.fillStyle = '#8fc97a';
    ctx.fillRect(0, groundY, W, H - groundY);
    ctx.strokeStyle = '#5a9c46';
    ctx.beginPath();
    ctx.moveTo(0, groundY);
    ctx.lineTo(W, groundY);
    ctx.stroke();

    // 태양 위치 계산 (막대기 기준점에서 왼쪽 위 방향으로 태양이 있다고 가정)
    const baseX = W * 0.62;
    const sunDist = 380;
    const elevRad = deg2rad(elevDeg);
    const sunX = baseX - Math.cos(elevRad) * sunDist;
    const sunY = groundY - Math.sin(elevRad) * sunDist;

    // 태양 그리기
    ctx.fillStyle = '#ffb703';
    ctx.beginPath();
    ctx.arc(sunX, sunY, 26, 0, Math.PI*2);
    ctx.fill();
    ctx.strokeStyle = '#ff9500';
    ctx.lineWidth = 3;
    for(let i=0;i<8;i++){
      const a = i/8 * Math.PI*2;
      ctx.beginPath();
      ctx.moveTo(sunX + Math.cos(a)*32, sunY + Math.sin(a)*32);
      ctx.lineTo(sunX + Math.cos(a)*42, sunY + Math.sin(a)*42);
      ctx.stroke();
    }

    const sticks = compareMode.checked ? [stickCm*0.6, stickCm, stickCm*1.6] : [stickCm];
    const gap = 130;
    const startX = baseX - (sticks.length-1) * gap / 2;

    let lastShadow = 0, lastMeasured = 0;

    sticks.forEach((h, idx) => {
      const x = startX + idx * gap;
      const stickPx = h * pxPerCm;
      const topX = x, topY = groundY - stickPx;
      const shadowLenCm = h / Math.tan(elevRad);
      const shadowPx = shadowLenCm * pxPerCm;
      // 태양이 왼쪽 하늘에 있으므로 그림자는 태양 반대편인 오른쪽 방향으로 생김
      const shadowX = x + shadowPx;

      // 태양 광선(막대 끝~태양)
      // 주의: 태양은 화면 위 고정된 한 점(sunX, sunY)에 그려지지만, 실제 태양 빛은 아주 멀리서
      // 평행하게 들어옵니다. 그래서 광선은 "고정된 태양 위치"가 아니라 실제 태양 고도 각도
      // (cos·sin 방향)를 그대로 사용해 막대 끝에서 뒤로 연장해야, 막대기 길이가 아무리 달라져도
      // 그림자(실)와 항상 정확히 일직선을 이룹니다. (고정된 점을 향해 그리면 막대기가 길어질수록
      // 실제 각도와 어긋나 보이는 오류가 생깁니다.)
      if(showRays.checked){
        const rayEndX = topX - Math.cos(elevRad) * sunDist;
        const rayEndY = topY - Math.sin(elevRad) * sunDist;
        ctx.strokeStyle = 'rgba(255,149,0,0.55)';
        ctx.lineWidth = 2;
        ctx.setLineDash([6,5]);
        ctx.beginPath();
        ctx.moveTo(topX, topY);
        ctx.lineTo(rayEndX, rayEndY);
        ctx.stroke();
        ctx.setLineDash([]);
      }

      // 막대기
      ctx.strokeStyle = '#6d4c2f';
      ctx.lineWidth = 6;
      ctx.beginPath();
      ctx.moveTo(x, groundY);
      ctx.lineTo(topX, topY);
      ctx.stroke();

      // 그림자
      ctx.strokeStyle = '#333';
      ctx.lineWidth = 4;
      ctx.beginPath();
      ctx.moveTo(x, groundY);
      ctx.lineTo(shadowX, groundY);
      ctx.stroke();

      // 실(막대 끝 ~ 그림자 끝) : 태양 고도 측정기의 '실' 역할
      ctx.strokeStyle = '#2a6fdb';
      ctx.lineWidth = 2;
      ctx.beginPath();
      ctx.moveTo(topX, topY);
      ctx.lineTo(shadowX, groundY);
      ctx.stroke();

      // 각도 표시(그림자와 실이 이루는 각 = 태양 고도)
      // 그림자 끝(shadowX)을 기준으로, 땅을 따라 막대기 쪽(-x, 즉 각도 π)을 시작 각도로 삼아
      // 실이 뻗어가는 방향(measuredRad - π)까지 호를 그리면 측정 각도가 정확히 표시됨
      const measuredDeg = rad2deg(Math.atan2(stickPx, shadowPx));
      const measuredRad = deg2rad(measuredDeg);
      if(showArc.checked){
        ctx.strokeStyle = '#e63946';
        ctx.lineWidth = 2;
        ctx.beginPath();
        ctx.arc(shadowX, groundY, 34, -Math.PI, measuredRad - Math.PI, false);
        ctx.stroke();
        ctx.fillStyle = '#e63946';
        ctx.font = 'bold 13px sans-serif';
        ctx.textAlign = 'right';
        ctx.fillText(measuredDeg.toFixed(1)+'°', shadowX-38, groundY-14);
        ctx.textAlign = 'left';
      }

      // 막대기 길이 라벨 (막대기 맨 위쪽에 표시해 각도 표시와 겹치지 않도록 함)
      ctx.fillStyle = '#333';
      ctx.font = 'bold 12px sans-serif';
      ctx.textAlign = 'center';
      ctx.fillText(h.toFixed(0)+'cm', topX, topY-8);
      ctx.textAlign = 'left';

      lastShadow = shadowLenCm;
      lastMeasured = measuredDeg;
    });

    shadowOut.textContent = lastShadow.toFixed(1);
    measuredOut.textContent = lastMeasured.toFixed(1) + '°';
    diffOut.textContent = Math.abs(lastMeasured - elevDeg).toFixed(1) + '°';
  }

  [elevSlider, stickSlider, compareMode, showRays, showArc].forEach(el=>{
    el.addEventListener('input', drawScene);
    el.addEventListener('change', drawScene);
  });

  drawScene();
})();
</script>
</body>
</html>
```

**사용법**: 위 코드를 Gemini Canvas(또는 캔버스 지원 환경)에 붙여넣으면 즉시 실행됩니다. 교사는 태양 고도 슬라이더로 "아침(낮은 고도)→점심(높은 고도)→저녁(낮은 고도)" 변화를 보여줄 수 있고, "막대기 3개 비교 모드"로 오개념을 교정할 수 있습니다. (테스트 완료: 브라우저에서 정상 작동 확인)
